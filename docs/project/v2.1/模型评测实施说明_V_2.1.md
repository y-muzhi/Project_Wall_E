## 2. 离线重建与检查

从独立工作区根目录执行：

```text
.venv/Scripts/python.exe -B tools/prepare-v21-evaluation.py --verify docs/verification/v2.1/evaluation-inputs-default-2026-11-19-v6.md
.venv/Scripts/python.exe -B tools/prepare-v21-evaluation.py --verify docs/verification/v2.1/evaluation-inputs-long-2026-11-19-v6.md
```

verify按清单Profile重建全部60样本/候选，不接受只挑一例后称全部一致。清单行包含Canonical、system、实际Wire、Output、八文本、实际HTTP请求体及覆盖摘要；请求体沿ModelGateway字段顺序和UTF-8原字节，Profile沿生产release规则，集合管理摘要另用排序JSON。输入配方SHA涵盖backend/app、冻结backend/resources及五个输入/资源生成工具；评价汇总工具/测试源码另在验证记录核对。没有读凭据、Tokenization、Chat或LIVE变更。

首次冻结可用同入口--manifest指定新的验证Markdown；长配置另给--profile deepseek-long-v3。--list只列固定身份。临时库/锁均由TemporaryDirectory回收，原始输出只在内存。

工具边界专项：

```text
.venv/Scripts/python.exe -B -m unittest discover -s tools/tests -p "test_v21_evaluation*.py" -q
```

本地受限环境的Windows异步循环需要可用的本地通信权限；不能因受限进程视图为空认定用户服务已停止。固定SQLite/外网和正常库防护运行方式沿[离线入口](运行与验收说明_V_2.1.md)；新观察专项在backend/tests/formation/test_v21_evaluation_bootstrap.py。未改前端无需为该工具重复前端构建或长负载。
