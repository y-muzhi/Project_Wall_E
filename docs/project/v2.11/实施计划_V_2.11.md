# WALL-E V2.11 实施计划

按用户提出的顺序推进，先在[待合并迭代](../../iterations/pending/v2.11/README.md)记录要求和验收条件，再实现、检查并更新[映射](../../traceability/v2.11/需求实现映射_V_2.11.md)。

| 顺序 | 事项 | 实施及检查 |
| --- | --- | --- |
| 01 | AI 回复头像对齐 | 在共享消息样式调整头像与正文排版，核对用户消息、时间戳与多行回退。执行格式、类型及现有会话专项，检查宽窄面板。 |
| 02 | 讨论进展读取失败 | 核对 5174 文档详情的实际响应，在现有读取边界处理文档形成摘要；用前端专项验证严格校验和重试，用需求 #2 验证页面恢复。 |
| 03 | AI 对话双状态 | 按[迭代设计](../../iterations/pending/v2.11/WALL-E.AI操作预设精简迭代V1_V_2.11.md)先接讨论／写入状态，再复用主题切换和章节范围校验，最后检查在途切换及恢复。 |
| 04 | 已接受请求的结果读取 | 核对原运行、隔离复现读取异常，修复实际后端投影，再按用户授权重启 8001 并只读验证列表、详情和页面。 |
| 05 | 中文 Markdown 加粗识别 | 分别核对原文边界和卡片说明的渲染入口，验证中文加粗、字面星号和线上只读显示。 |
| 06 | AI 输入区纵向空间 | 横向排列常用控件，检查窄面板换行、两种状态的可操作性及输入框高度。 |
| 07 | 恢复 V2.1 文档形成主线 | 核对 5174 与原工作区，按共同基线合并文档形成端到端入口并保留 V2.11 交互。 |
