## 资源准入与隔离观测工具

准入绑定同一release、profile及原正常LLMUse／计数审计。v10冻结资源文件保持OFFLINE_READY；普通调度读取正常审计目录中的准入引用并重新核实原始证据，异常实际用量从正常LLMUse持久推导SUSPENDED。不能用改配置状态、旧版观测或新的成功样本消除同release的异常。

默认预览完全离线：

```powershell
.\.venv\Scripts\python.exe tools/observe-v15-once.py
```

它使用退出即清理的临时新库，显示release、实际编译文本摘要、字符数和固定预算；不读取环境密钥，不计数或调用Chat。预览中的文本摘要用于检查当时编译结果，不承诺与另一次运行的时间／身份相关字段相同。

以下真实执行命令仅为后续获当前授权后的启动说明，本轮未执行；启动前必须确认允许的计数批次数、1次Chat及完整预算。命令必须显式提供全部参数，示例只允许最多1批计数，不能在失败后改用另一个目录重试：

```powershell
$observationDirectory = Join-Path (Get-Location).Path 'data/v15-observation-NEW'
.\.venv\Scripts\python.exe tools/observe-v15-once.py --execute --output-dir $observationDirectory --allow-count-batches 1 --allow-chat-calls 1 --max-total-tokens 139264
```

output-dir必须是父目录已存在的绝对新目录。程序以原子mkdir占用本次槽，现有目录一律拒绝；不提供复用、继续发送或自动重试开关。输入131072、输出8192、总量139264及framing预留1024保持冻结；每批至多一个计数请求，明确允许时最多3个不同候选、1次Chat，transport_retries=0。计数／Chat额度在IO前消耗，超时或未知结果不返还。

执行使用正常ModelProfile环境配置及固定供应方端点，创建唯一新需求和DISCUSS运行，不产生正文，不启动HTTP／Worker服务。正常observation.sqlite及旁边计数审计必须保留，失败／取消／中断也保留；不能当测试临时产物删除后重跑。请求快照保存OFFLINE_READY和私有observation预算；Wire不携带此程序权限。仅实际返回、精确计数／请求及用量都合格后为隔离库记录LIVE_VERIFIED，技术准入不能代替语义效果EV验收。

只读查看某个已有V1.5库的当前准入（无provider IO）：

```powershell
.\.venv\Scripts\python.exe tools/admit-v15-resource.py --database C:\absolute\target.sqlite
```

明确导入原正常观测调用到目标库的程序配置（不改业务正文、不调用provider；在目标库OS锁下执行）：

```powershell
.\.venv\Scripts\python.exe tools/admit-v15-resource.py --database C:\absolute\target.sqlite --approve-saved-call --source-database C:\absolute\v15-observation-NEW\observation.sqlite --llm-use-id 1
```

目标必须是现有schema150库，原证据库须持续可用；路径或内容损坏将拒绝调度，不自动回退放行。两个工具均不代替用户对服务启停或真实调用的当轮授权。本轮实际证据仅为隔离离线专项。
