## 本机使用

项目根 `.env.local` 保留单行 `WALLE_MODEL_API_KEY=本机密钥`，不要提交该文件。已有数据库和前端构建时运行：

```powershell
.venv\Scripts\python.exe -X utf8 tools/ai-service.py --start
```

打开 `http://127.0.0.1:8000/requirements`。普通用户操作触发正式 AI，沿用每个逻辑调用最多三次 Chat 尝试；后台不会自动提交新业务输入。详细安装、启动及停止见 [运行说明](运行说明.md)。本批没有构建前端、没有恢复浏览器或完整验收；373 项验收状态不因此改变，模型真实业务效果尚未完整评估。
