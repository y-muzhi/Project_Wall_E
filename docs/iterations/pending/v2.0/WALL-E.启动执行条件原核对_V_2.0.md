# V2.0 启动执行条件原核对

2026-11-08，依据 BE START.CHECK_CONDITIONS、APP-CODE-CONDITIONS、7.2.6、7.3、7.4.4。正式设计保持原样。

原工作区完成时追加不可替换的私有文件清单，绑定已有固定内容摘要。启动条件检查从原工作区证据核对真实根、目录、每个文件的类型和完整字节，并使用固定配置的文件数、字节和核对期限，复核整份已封存依据、同任务原授权／配置及预算。旧工作区缺原清单时明确保持内容待核对，不能凭目录存在放行。该步骤不从源仓库补写工作区，不请求真实模型或启动进程。

完整固定内容核对与运行环境准入分开记录。没有真实执行器、隔离及模型准入时，保留原检查失败和缺失的能力，START 原 202 继续可查询。失效或已停止时不采用迟到结果。实际执行器路径与隔离配置按 7.3／7.4.4 后续接入，条件检查的阻断结果不会生成 ManagedInstance 或会话。

系统受管来源使用 Windows Known Folder 的 ProgramData 真路径及本地目录句柄，只读核对 opencode 项。存在任何同名项或无法核对时，列入 Q20-CONFIG 缺项，不按进程环境值改写系统来源，不创建或修改文件。正式启动前仍需在实际隔离身份下取得运行配置、只读依赖、授权及网络证据。 [Microsoft Known Folders](https://learn.microsoft.com/windows/win32/shell/known-folders)
