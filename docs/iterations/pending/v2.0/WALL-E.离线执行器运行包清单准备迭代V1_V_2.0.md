# 离线执行器运行包清单准备 V1（V2.0）

2026-11-13，实施前登记，pending不合并正式设计。依据BE7.4.4完整离线依赖及运行包准备／核对规则；补齐已有check-opencode-binary.py只能校验人工清单的准备缺口。

输入为操作者明确给出的已有离线运行目录和新的清单输出位置，不下载、不安装、不执行包内代码，不创建执行配置或更改准入。输出使用现有OC20-CONFIG-1 manifest及opencode-bundle:sha256引用，逐实际NTFS身份、逻辑路径和有界完整字节生成；复用既有_inventory／_verify_tree／_verify_control_files重新检查闭包、配置及锁定依赖，避免第二套准入规则。

清单目标必须在源树外且不存在；完整内容先临时写入同目录、fsync并关闭，调用既有正式校验器验证临时清单，最后以同卷原子无覆盖发布。遇到已有目标、目录／文件身份或字节变化、取消／超时、无效锁文件／扩展配置均失败，不修改源树，不覆盖原清单；成功／失败都清理自己的临时文件。

仅准备元数据，不证明执行器二进制、只读DACL、SYSTEM／LPAC／WFP、原生协议或模型准入。源树后续改变仍在正式运行前重核。测试只用隔离假包并清理，不能登记为真实OpenCode发布或安装证据。
