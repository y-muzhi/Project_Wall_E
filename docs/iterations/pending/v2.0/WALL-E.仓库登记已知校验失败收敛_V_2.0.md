# 仓库登记已知校验失败收敛

沿 BE APP-CODE-SETUP、OBJ-CODE-OPERATION 和已确认的首次登记原 202 接收方案。登记 worker 在原 VALIDATE 已开始后，遇到已明确的来源路径／占用／配置／元数据拒绝，只在原 Guard PREPARE 从未记下派发可能，或者原 RELEASE 已确认清理，且本地读取句柄全部关闭后，记录 VALIDATE 和原操作 FAILED。SAVE_FACT 保留未开始，预留仓库不创建，原 202 不改写。另一个请求不能复用该原范围开始派发。

原 PREPARE 可能已经派发且尚无可靠 RELEASE 时，原操作继续 UNKNOWN，不能用来源错误代替停止和清理证据。未识别的内部错误及数据库提交未知先核对原状态，不在通用异常分支伪造确定失败。校验错误只公开现行失败编码，内部路径及原系统错误保留在所属错误对象内。
