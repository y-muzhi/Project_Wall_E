# WALL-E 仓库登记表单与原操作视图

2026-11-07，V2.0 待合入迭代。依据前端 BND-CODE-SETTINGS 5.2—5.5、SHR-FE20-LIFECYCLE／7.4 和用户已确认的 C01 202 原登记契约。

- 仓库分区提供名称与本机目录文本输入，按同源标签页暂存，切换分区保留。仅显式提交冻结原字段并由 CommandRecovery 先保存原命令，再发 C01。原未决时引导到既有待核对区，不生成替代键。输入校验、服务拒绝和未知保留原草稿；可核实原登记失败后允许重新编辑和明确提交。
- 202 后显示已接收及原操作 ID，保留匹配输入直到确认原操作成功。操作详情只读 API17，校验原操作 ID、登记类型、原键和已经核实的仓库 ID。状态为成功时才提供查看已保存仓库；等待、失败、未知和读取失败分别呈现。操作失败时保留匹配草稿。历史操作完成只更新自身，不清后来输入。
- 暂存只恢复输入、原键及已接收的查询定位，不作为服务端完成证明。恢复沿已有 IndexedDB 原记录，操作详情读取可取消，暂存失败只保留本页内存。登记结果及检查边界与 C02 观察刷新、实际 Windows 部署分开记录。
