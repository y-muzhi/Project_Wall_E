# 区块左侧操作菜单与悬停高亮

日期：2026-10-30。编号：M15-BLOCK-MENU-01。来源：用户飞书截图及四项要求：文档右移留按钮位置、悬停区块浅蓝高亮、操作按钮移入／点击展开左侧操作栏、操作栏先放来源及评论区块。

依据：正式FE BND-EDITOR／SHR-UI／公共浮层规则，以及V1.0沿用的区块辅助栏和评论契约。以下可见交互替代原“区块右侧直接展示辅助栏”，本条尚未合入正式设计；区块仍以既有顶层Block身份确定，不为列表每行或表格单元格制造新ID。

1. 正文编辑器左内边距增加44px，给区块按钮留出独立沟槽；文档元数据、全局导航及格式工具栏保持原归属。高亮使用#EDF2FF浅蓝底和同色4px外延，不改变正文大小或字重。
2. 悬停、正文键盘定位或选区交互后，高亮当前真实Block，左侧出现28px操作按钮。不同Block之间移动替换高亮；离开正文与操作区且无相关焦点时延迟180ms收起，让鼠标可跨越按钮与菜单之间的间隙。来源浮层打开时冻结实际目标，关闭后再跟随新的区块。
3. 操作按钮移入或点击展开160px宽的左侧菜单；左侧空间不足时在按钮下方展开，并夹在视口内。只显示“来源”“评论区块”两项。来源沿原非模态浮层和真实来源元数据；评论沿原commentTarget／panel.create，不因菜单引入新请求或放宽权限。人工草稿／历史视图评论按钮禁用并说明原因。
4. 原“评论选区”从区块菜单移至选中文字上方的独立浮层，保留同一区块及快照校验；菜单不重复该入口。已有评论标记与数量仍由原CommentMarkerLayer显示。
5. ArrowDown可从按钮进入菜单，菜单上下键／Home／End导航；Esc先关闭来源，再关闭菜单并回操作按钮，点击外部关闭。滚动离屏、输入无效、隐藏或销毁时清除高亮、定时器与浮层；不改编辑器文档或序列化结果。

实现：documents/navigation.ts、navigation-view.tsx、comments/panel.tsx、shared/styles.css及icon.tsx。继续work分支并保留此前新建入口修正；不提交／推送、不修改用户数据或业务服务。[实际检查](../../../verification/v1.5/block-menu-2026-10-30.md)单列范围和边界。
