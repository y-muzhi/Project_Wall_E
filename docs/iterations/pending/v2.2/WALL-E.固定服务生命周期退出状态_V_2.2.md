# WALL-E V2.2 固定服务生命周期退出状态

2026-11-24。依据冻结的 V2.01 后端 4.5、4.8、7.9、7.10。适用于由固定启动器持有监听套接字的普通、只读及管理服务。实测普通进程在 ASGI 关闭抛错后、管理进程在关闭抛错或重复 SIGINT 跳过关闭后，旧入口仍可给出退出 0。

普通与管理服务共用固定 Uvicorn 的退出判据。正常启动且实际收到无错误的 ASGI 关闭完成才返回 0。已进入运行但退出时关闭失败、未完成或跳过，返回 2。保留固定 Uvicorn 启动阶段失败的退出 3。管理服务显式开启 ASGI 生命周期。各服务原信号响应方式、监听清理和业务终态依据由各自原入口管理。

返回值只说明当前进程的生命周期结果。普通环境的停止和容量变动仍需原运行、持久控制、稳定锁与宿主核对共同确认。管理入口退出不得补写普通环境停机、容量释放或发布结果。
