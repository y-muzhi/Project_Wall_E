# WALL-E V2.2 Agent 启动端点的 Linux 原型

状态为本机机制调查。依据 V2.01 后端 7.11.10、8.2 P2-a。R336 的受保护 pathname 端点在独立挂载和强制策略下拒绝连接。R348 证明在每原实例私有网络内以精确抽象 SEQPACKET 名称和双方强制标签限制的候选可保留独立挂载，阻断同 UID 错角色绑定、连接及跨独立网络连接。

这一证据仅覆盖报文端点。R350 的双方直接 systemd 查询仍受路径断开阻断，不以 socket 身份或自报 PID 代替 `GetUnitByPIDFD`。只有查证原 MainPID、InvocationID、固定程序及完整强制标签之后才继续假凭据试验。关闭描述绑定、逐报文凭据、拒绝 FD、一次交付、同一 PID 受限 exec、原能力与停止流程均保持。完整证据未取得时继续显示内部 Agent 未准入。R356 证明独立只读观察者可在保留真实专属网络及 Agent 独立挂载的条件下连接系统总线，但实际精确方法被强制策略拒绝。没有采用替代观察者或放行后续假凭据交付。原 V2.01 资料保持原字节。
