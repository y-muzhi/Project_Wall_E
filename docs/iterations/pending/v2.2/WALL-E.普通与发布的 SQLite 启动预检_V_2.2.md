# 普通与发布的 SQLite 启动预检

2026-11-24，依据 V2.01 后端 4.2、4.11、7.10。普通启动和固定目标开放使用原环境稳定锁。读配置、解析启动资料或绑定套接字不取得活动 SQLite 的读取资格。

- 普通及固定程序在启动恢复前先取得环境稳定锁，再执行原库结构、完整性、安装及代次预检。无锁直接调用预检拒绝。锁内按有无侧文件选择既有读取方式，保留无侧文件时的无写入性质。
- 固定恢复代次仍执行原只读冻结核验。期间不增加旧任务恢复写入或供应方动作。传统启动沿原进程锁和预检次序。
- 稳定锁忙时直接报告原忙原因。预检或后续启动失败释放本次已取得的锁，原数据、控制和未知结果按既有规则核对。
