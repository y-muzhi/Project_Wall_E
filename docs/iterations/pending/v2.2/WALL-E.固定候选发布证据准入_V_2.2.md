# WALL-E V2.2 固定候选发布证据准入

2026-11-21。依据 V2.01 后端 4.11、7.10 和 8.1.3，接续 R5 的独立检查引用。原检查状态继续用于读取已记录事项。

- 候选证据准入逐项核对离线构建、独立应用、浏览器业务与恢复。四类证据均从原候选清单的已钉摘要记录读取，并复核平台、程序、前端、资源与原交付关联。缺证据明确列缺项。存在失败或未能得出结论时保持阻塞，同类成功证据不覆盖已有阻塞。
- `candidate --require-release-evidence` 读取实际最终候选。四类证据不完整或有阻塞时，以非零退码留下原候选结果及具体证据缺项。单独封存、准备候选和继续独立验证仍可执行。
- 四类证据齐备表示当前固定候选的证据门槛满足。目标配置、程序与数据兼容、受信恢复点、维护与生产开放各按原契约核对。
