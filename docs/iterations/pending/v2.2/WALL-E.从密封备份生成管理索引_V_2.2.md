# WALL-E V2.2 从密封备份生成管理索引

实施条目 R25。依据 V2.01 后端 4.12.1、6.6.2、7.10。为 R24 的真实入口生成独立、可固定采用的恢复资料索引。

- 受信导出计划固定管理登记作用域、环境、观察时间、备份政策、最近尝试和一组实际 R15 备份。按实际私有根及清单摘要复验每个备份，提取安全来源、截止时间、资产范围与发布关联。
- 可选本机 R21、Restic 本地 R23 证据需要明确原键、清单和范围匹配。生成的索引和支持回执置于新保护目录，完整核对后原子发布。同一计划可读回原目录，已有意图不同时停止。
- 成功回执提供给管理 catalog 的路径和摘要引用，管理 HTTP 仍只展示安全投影。目录准备不会安装、替换或重新启动现有的登记和业务服务。
