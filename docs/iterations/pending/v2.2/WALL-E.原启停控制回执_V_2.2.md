# WALL-E V2.2 原启停控制回执

2026-11-21。依据 V2.01 后端 3.5、4.6、4.8、6.5.2、7.9。使用现有原操作、步骤和 `management_controls`，保留内部管理入口。

- CONTINUE 仅处理容量等待的原 START，并重新核对主体、原操作版本、环境与分配、实际观察和可用容量。容量仍不足时更新等待依据。获得额度时，同事务从原步骤转为已受理并预留。不会派发宿主命令。
- CANCEL 在原 START 未进入派发提交点且无宿主执行记录时，原子标为已取消、跳过原步骤并释放准确预留。派发进入待核对后只登记取消请求，保留原占用，后续由受信物理控制核实。明确请求取消后重新进入固定启动步骤，只能读取已开始过的派发事实。
- RECONCILE 读取原宿主事实，沿原步骤核对，不触发启动或停止。丢回执按原 operation_id 与 control_key 取回，保留独立控制回执。重复键先查原控制；不同主体、目标或输入不得套用同一控制。
- 浏览器写入在固定派发和运行取消闭环验证前保持关闭。普通应用验证入口继续独立可用。
