# WALL-E V2.2 普通启动与恢复资料的实际证据

状态为实施补充。依据 V2.01 后端 4.6、4.10、6.6.2，前端 5.9、5.10。原设计保留。

受管普通启动首次受理及等待额度后继续均须核对当前绑定的新鲜正常停止观察。观察缺失、过期或变更不得新增原受理或保留新额度。原操作及已经持久的控制结果仍按原键读取，实际派发另行核对物理资源。

恢复控制明确要求恢复时，只有当前部署、数据代次及控制版本相符的只读核验才可展示资料可用。当前未登记可用证明的原因分别从宿主状态、部署与数据绑定、外发冻结及只读资产取证中投影，页面继续显示准确的待核对项。已证实的普通停止与非恢复维护显示该资料观察不适用。同结构发布在原执行与完整目标同时相符时，可以停在锁定的发布目标并保持关闭。仅凭相同部署 ID 或原公告不得认定目标选择成功。

只读应用用受保护策略的 SHA256 作为核验引用。管理应同时核对现行关闭维护、冻结、数据代次、部署及控制修订。已有资料可读与原恢复操作仍待核对可同时成立。备份点只显示已实际获得的核验时间、范围及原操作资料，恢复目标和实际耗时分别显示。
