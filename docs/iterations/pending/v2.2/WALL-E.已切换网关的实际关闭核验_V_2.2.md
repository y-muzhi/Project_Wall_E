# WALL-E V2.2 已切换网关的实际关闭核验

2026-11-21。实施细化，对应 V2.01 后端 4.11、7.10。R32 装配只固定输出，R33 需独立观察已在现场加载该固定配置的网关。

- `verify-release-gateway` 绑定网关固定文件、原关闭记录、专用 Caddy 进程、TLS 本地 CA 和受保护的只读账户。核对监听 PID、可执行文件、启动参数及启动标识，只连接本机固定地址。输出仅包含身份和摘要。
- 以实际 HTTPS 核对无认证拒绝、已认证的公开配置、新首页、新版资源、原版专属资源，以及普通工作台接口在后端未启动时仍无准入。读取真实新旧前端索引以确定字节。过程中保持维护冻结和同一程序、控制、数据身份，出错保留关闭。
- 现场网关核验和固定程序关闭核验均是重新开放输入。网关核验不改变控制、不重启服务、不创建业务资料。
