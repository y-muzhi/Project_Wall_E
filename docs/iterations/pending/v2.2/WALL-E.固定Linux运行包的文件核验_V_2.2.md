# WALL-E V2.2 固定 Linux 运行包核验

依据 V2.01 后端 4.1、7.2、8.2.1。R499 分段测得固定运行包的文件核验耗时高于私有恢复探针的原等待上限。运行包目录遍历中，每个登记文件曾重新构造路径、重新解析同行清单并再次查询文件状态。

固定清单、逐文件 SHA256、完整文件集合、目录保护及文件权限约束继续执行。校验在已保护根目录内按目录描述符遍历。每个文件通过无跟随打开并核对实际文件句柄的类型、链接数、所有者、权限及字节数，再读取同一文件描述符计算 SHA256。目录逐层禁止跟随链接，检查所有者和写权限。未登记项、缺项、路径冲突或内容变化均拒绝。索引和清单继续按各自固定摘要校验。核验不跨进程缓存结果，不使用文件时间戳替代哈希。

成功条件为当前固定 Linux 来宾完成正反验证、定位实际耗时差异，并在保留 35 秒启动和原关闭门槛的前提下重复私有恢复应用验证。普通安装、候选及发布采用同一套运行包验证逻辑。正式构建与发布时间另按受信来源执行。
