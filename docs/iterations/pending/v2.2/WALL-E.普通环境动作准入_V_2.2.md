# WALL-E V2.2 普通环境动作准入

实施依据为 V2.01 后端 4.3／4.4.1 和前端 4.2。C9 只接入握手已经核实普通文档读写的浏览器。普通应用保留需求、文档、人工草稿、版本及评论和消息的已有读取。允许新建需求、创建文档、开始／保存／完成／取消人工编辑；旧初始化入口仍由后端核对原封闭状态。保留原代码和测试命令的回执只读入口。

当前环境尚未开放的操作在客户端请求边界明确拒绝。被拦截的原命令可保留原输入和标识，客户端不创建 HTTP 回执。服务端仍独立核验主体、请求来源、环境与动作。无绑定的旧应用调用保留原准入路径。

普通详情用已有工作台、文档和评论组件。尚未接入的需求属性、状态、文档属性、评论写入、人工版本说明和 AI 卡片提交分别显示对应原因。已保存消息、评论和正式内容可继续读取。没有登记入口的代码、测试和设置页面展示明确的未开放状态。后续启用由同版握手与后端契约推进。
