# WALL-E V2.2 原运行正常停止的受信执行步骤

2026-11-20。依据 V2.01 后端 4.5、4.6、6.5、7.9。延续 M9 的受信运行观察，为管理原 STOP 步骤准备实际宿主执行入口。

- 受保护意图固定管理安装及登记代次、环境、原运行、停止操作号和原受信运行策略摘要。执行前复核实际进程组、原操作、资源限额、应用归属和 systemd 正常停止策略。仅处理当前已核实的普通运行，服务组派生自原环境及启动操作，操作输入不包含 shell、服务名或任意 PID。拒绝带强制终止、异常信号或自定义停止命令的单元。
- 受信目录按原运行串行记录派发意图，先持久化再调用固定 systemd 停止动作。确认原服务组清空、原锁释放、连接关闭及原控制已正常 CLOSED 后，封存原停止回执。原运行已核实停止时保留同样的明确结果，无需派发。
- 中断或命令结果未知时继续核对原运行，从持久意图查回结果。再次执行原动作不重复停止；其他停止意图不能代替未决意图。该记录只证明宿主一步的实际效果，供后续管理事务关联和额度释放。
- 本单元不改变原业务启动器及 Schema 来源。界面启停、管理层受理及容量释放待完整连接后才能开放。
