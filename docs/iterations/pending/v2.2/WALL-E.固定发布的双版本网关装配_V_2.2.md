# WALL-E V2.2 固定发布的双版本网关装配

2026-11-21。实施细化，对应 V2.01 后端 4.11、7.10。普通网关原先要求开发与集成使用相同程序快照，单环境固定发布需要逐站核验各自实际固定程序并保留另一环境。

- 固定上一部署、新部署、原关闭选择、新版核验回执、上一前端索引及另一环境锚。新的公开配置和首页来自目标安装。普通 Unix 上游和登录规则保持各环境归属。
- 同一站的 `/assets/*` 优先使用新固定目录，路径不存在才使用已核对的原目录。相同路径不同内容时拒绝。两套固定静态目录分别保留。
- 生成独立 Caddyfile 与装配回执。此步结束于可查验的独立文件，后续再核实实际认证、静态文件和关闭状态。
