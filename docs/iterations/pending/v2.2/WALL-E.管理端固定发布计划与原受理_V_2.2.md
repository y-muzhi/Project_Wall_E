# WALL-E V2.2 管理端固定发布计划与原受理

2026-11-21。实施细化，依据 V2.01 后端 3.5、3.7、4.10、4.11、6.5、6.6.2、7.9、7.10。沿用已有管理库、原操作、固定候选和 R26—R35 实际发布工具。

- 首个管理接续覆盖普通开发与集成环境的同结构发布。管理员从已登记候选、预备安装、兼容和备份策略选择。宿主在原稳定锁下核对源已正常停止、无旧套接字、源控制版本、目标安装、固定程序、前端、Schema、配置及同一环境和数据代次，产生与宿主和登记代次绑定的有时限观察。当前已正常停止再生成计划，以便复用已有普通 STOP，在线维护收尾另行接续。
- 管理端存实际计划和期限。预览给出源／目标部署与配置、程序摘要、要求能力、已登记候选及备份规则。必须确认固定计划摘要、环境版本与分配版本。计划、原请求键、操作者、固定原操作和环境互斥进入同一 SQLite 写事务。相同原键和输入读回同一结果，异输入报冲突。管理受理只给后续宿主步骤原操作依据，受理事实不表示停止、切换、运行或开放。
- 宿主后续依据已受理操作，原维护、停写备份与恢复证据、目标控制、实际验证及开放都须使用同一原操作。受理阶段本身只执行离线登记，目标进程派发前另取得并实际落实已配置容量与启动资格。不得把浏览器提供的路径或自报状态当作事实。
