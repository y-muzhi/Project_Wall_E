# WALL-E V2.2 恢复组件的同源核对

2026-11-21。依据 V2.01 后端 4.12 和 7.10。接续普通资产覆盖、原结果索引和隔离新根，核对它们是否属于同一原捕获。

- 维护身份使用受保护的核对计划，固定原捕获计划、原结果索引策略、恢复计划与各自结果摘要。三个组件必须来自同一环境、原数据代次和同一原捕获，并持有各自固定文件。核对资产覆盖在原控制窗口内取得，重开新恢复库核对新代次、原初始化时刻和原类型化数据；原结果索引每个分片均重验。
- 仅报告原数据、恢复副本及原结果索引的绑定和摘要。封存后的原业务库与计数审计不改写。错原捕获、错新代次、丢失或篡改组件均阻断。
- 返回事实供完整恢复清单使用。封装、隔离运行演练及外部保存是独立步骤，核对结果没有开放或采用目标的权限。
