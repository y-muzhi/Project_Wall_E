# WALL-E V2.2 固定目标的独立进程核验回执

2026-11-21。实施细化，对应 V2.01 后端 4.11、7.10。使用原关闭选择及新版私有核验入口。

- `verify-release-deployment` 以固定运行包和新安装为准，由独立宿主观察者创建限定身份的实际核验进程。使用独立家庭与临时目录，通过原稳定锁和 Unix 对端 PID／UID／GID 检查归属。验证实际握手、停写选择、指定现有正文及历史，拒绝写入、外发和错误数据代次。
- 只停止本次启动的进程。停止后查实际锁释放、私有套接字清理、原控制及 SQLite 身份未变，再在专用受保护目录排他发布固定回执。同 ID 同结果可再次读回，仍须核对窗口状态。缺证据、错误身份、定位到其他进程或不明停机时维持关闭。
- 回执仅绑定这次实际关闭验证，记录确切原计划、新部署、核验身份、逻辑及正文摘要。公开入口和 OPEN 在之后的原操作中核对，不能以历史回执代替当次控制与启动验证。
