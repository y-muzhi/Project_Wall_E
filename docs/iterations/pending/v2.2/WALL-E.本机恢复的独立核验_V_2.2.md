# WALL-E V2.2 本机恢复的独立核验

实施条目 R21。依据 V2.01 后端 4.12.1、4.12.2、4.22.2、7.10。以 R20 已封存且无对外入口的专用恢复安装为输入。

- 核验计划固定目标安装与 R18 读回计划，使用专用身份的私有 HOME／临时目录，绑定一个有内容的原需求、正文和可核对的预期文字摘要。受信核验器只启动本轮归属的子进程，核对 Unix 通道对端进程和真实稳定锁一致。
- 从实际恢复应用读取握手、需求、正文、原注释索引和历史。要求正文摘要一致、原代次请求被拒、写操作和未核验操作被拒。检查停止前后控制和数据库摘要，确认专用套接字和锁释放。
- 成功生成独立的本机恢复核验记录，绑定原备份清单、演练回执和本次固定部署。普通资料范围可记 `LOCAL_VERIFIED`。计算所有证据只记录元数据和摘要。其他恢复能力、旧外发核对、异机状态和正式采用仍按原规则。
- 未授权、不一致、临时异常及终态无法复核都停止生成成功结果。仅本轮拥有的进程和私有试验资源参加清理。
