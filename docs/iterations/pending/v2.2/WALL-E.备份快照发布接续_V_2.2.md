# WALL-E V2.2 备份快照发布接续

依据 V2.01 后端 4.12.1、6.6、7.10 及 8.1.3 TC201-REL-10／11。原 R23 可按完整 Restic 快照 ID 取回并核对封存包。本批增加原封存包首次发布、断回执恢复与原结果读回，复用同一备份包完整性和实际取回校验。

- 固定原封存目录、包摘要、Restic 二进制、仓库身份及专属工作目录。不改备份截止点。首次派发前同步原意图，按精确操作、包和清单标签查找唯一快照。
- 退出状态、标签和快照列表不足以证明包完整。先用原快照 ID 实际取回并读回已有包结构，比较全部闭包，再写持久回执。故障或已有事实不匹配时保留原意图，只核对，未知路径禁止二次写入。
- 本批入口仅处理本地已安装仓库，回执表明固定内容已发布和本地取回。云存储、异机恢复资格、凭据样本及生产采用须经单独准入。禁止通过本地回执给出 `OFFHOST_VERIFIED`。

R169 将已受保护的发布回执接入原备份索引。公开摘要继续使用已有本机取回证据字段。只有复算的原发布意图、固定快照、封存包、时限及数量均有效才展示。异机状态按原规则单独核验。

## R176–R179 异机取回和时效

依据 V2.01 后端 4.12.1、6.6.2、7.10、TC201-REC-09／10，前端 5.9 与架构评审 3.4。先做受信索引与管理投影，再接独立取回和实际操作门槛。

- R176 在原受保护恢复点索引增加版本 2。只有登记的来源宿主／独立验证宿主、验证安装摘要、固定仓库及存储配置匹配，且独立取回证明绑定同一备份、来源代次／部署、截止时间、清单、逻辑内容和完整快照时，才标记 `OFFHOST_VERIFIED`。仍要求原本机恢复演练证据，旧索引保留原义；库外秘密及宿主路径不出现在 HTTP。
- 异机时效按最新有效异机点的原截止时间计算。较新的失败或本地点保持分列，较新的验证时间不得代替截止时间。异机验证的观察有效期由受信计划明确配置，过期、没有时效目标或没有可信异机点为 `UNVERIFIED`。原索引超过当前时钟时保持受控错误，不能报告达标。
- R177 接受信离线出口把经核对的异机证明封入原恢复点索引。既有本地发布回执不得转作异机证明。R178 独立取回由受信源宿主上传命令与独立验证宿主取回命令接续。两端配置通过固定目录的宿主安装记录、实际 Linux machine-id 摘要、独立的非 root 维护身份、受保护密钥文件及精确仓库配置准入。固定 Restic 使用 COS 区域端点、HTTPS、DNS 桶寻址和显式区域。上传只形成已知快照引用，验收工作机必须与源宿主身份不同并实际完整取回，才生成异机回执。命令不自注册仓库、账号或外部资源。R179 接受管发布、程序回退及配置切换的严格异机门槛。版本 2 的已登记恢复策略固定递交的来源宿主、独立验证宿主、仓库和验证安装。选择目标前，沿原持锁关闭及备份计划核对同一包的独立取回；缺失、仅上传或错包保持关闭。已选择回放继续使用原事实。R180 让版本 2 已登记备份策略进入现有独立 `BACKUP`。完成前可保留同包的本机演练和“等待异机取回”状态；异机证明缺失、未取得或核对失败，继续保留原操作和原截止。收到符合原宿主、仓库、包和快照的保护回执后，原管理操作才允许记为成功。同键回放不再次捕获。普通策略仍沿版本 1。
- R181 对本地与异机共用的 Restic 子进程施加输出上限和整次子进程时限，超限、超时或取消仅清理原子进程，保留可疑外部结果待按原键核对。供应方输出与凭据不写入服务日志。
- R183 增加受信的恢复包物化入口。先按已获准的验证宿主、原快照、原取回回执和实际接收目录再次核对，实际取回后以独占方式放置完整封存包，供现有恢复工具按路径、身份和清单摘要消费。回执丢失按原意图重读，禁止覆盖已有目录或直接开放业务。
- R184 依据后端 4.12.2，把已登记的异机核验恢复点接回现有普通恢复。选择严格策略时，版本 2 的恢复预检固定同一来源／验证宿主、仓库及原异机取回回执，管理预览须匹配原恢复点的证据，物理预检须重新验同一包和现有本机只读演练。恢复宿主上的包由既有受保护验包策略固定本机目录身份，跨宿主交接后重新核验同一内容，不复用异机文件系统身份。管理确认显示异机取回时间和快照。原源保全、同环境 ID、新代次、关闭和外发冻结要求继续适用。版本 1 的本机策略仍可使用已进一步取得异机证据的本机已核验恢复点。
- R190 在确认前若原异机回执消失、改写或无法核实，管理入口报告原计划已变化，事务不消费原计划或请求键。只有重新提供已固定的原回执才可按同一原确认重试；持锁物理预检按不可核实拒绝。
- 真实 COS、异机宿主、恢复材料的可用性与生产采用需要实地准入。隔离夹具在实现、验证与映射中分别标明。

命令语义参考 [Restic 0.19.1 脚本接口](https://github.com/restic/restic/blob/v0.19.1/doc/075_scripting.rst) 及 [备份标签](https://github.com/restic/restic/blob/v0.19.1/doc/040_backup.rst)。
