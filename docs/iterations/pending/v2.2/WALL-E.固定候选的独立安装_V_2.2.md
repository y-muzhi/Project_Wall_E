# WALL-E V2.2 固定候选的独立安装

2026-11-21。依据 V2.01 后端 4.11、7.10 和 8.1.3。普通 P1 的开发与集成范围保持原有契约。本次为 R 单元增加独立 CANDIDATE 入口。

- Linux 受信宿主使用固定预备计划，指定候选目录登记、原集成交付、发布文件清单摘要、独立环境和代次、部署、根身份、专用进程身份。当前注册管理程序以自己的只读身份核对原集成交付和候选，宿主再核对相同程序、前端、Schema 与实际受信运行包。
- 候选程序使用发布封存的应用目录、程序快照 pin 与 Schema。验证站点只服务原固定前端的私有副本，使用独立来源和认证。固定目的为 CANDIDATE，业务沿普通无外发装配，不复用开发、集成、生产身份或业务数据。此入口预备安装，后续仍由既有初始化和启动器验证，不在安装时创建测试要求或文档。
- 原安装的计划、固定身份和内容相符才可取回。目录不完整、其他计划或部分状态不明时保留并停止，不能不断生成新根来掩盖原结果。固定构建、独立安装、真实运行及正式发布分别有证据。
- 单独候选网关仍使用受信 HTTPS 和精确来源，不修改共享日常入口。外部供应方、生产切换及已有环境更新不属于本条。
