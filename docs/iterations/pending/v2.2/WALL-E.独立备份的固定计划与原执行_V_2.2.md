# WALL-E V2.2 独立备份的固定计划与原执行

状态为实施补充。来源为 V2.01 后端 4.10、4.12、6.6.2、7.9 和前端 5.10。原设计保留。普通现行部署已真实正常停止、没有运行额度或进行中操作时，管理者可按已登记策略预览并一次确认独立恢复点。先前为停止时，选择恢复之前运行仍保持停止。备份 ID、源配置与数据代次、覆盖要求和原控制一起固定。按既有封存契约，备份 ID 同时作为物理捕获子操作的原 ID，管理根操作另有自己的 ID。独立执行、异机取回和恢复后的实际准入各按证据推进。初次只准入本机已验证策略，要求异机的策略须保留其要求。旧捕获回执使用 UTC 的 `+00:00`，管理时间投影规范化为 `Z`。原回执及完整摘要保留。
