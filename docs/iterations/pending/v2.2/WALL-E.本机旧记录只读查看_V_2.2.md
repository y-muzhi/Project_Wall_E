# WALL-E V2.2 本机旧记录只读查看

依据 V2.01 前端 5.3、5.4、7.5 和 TC201-FE-08。普通或恢复业务页提供本机旧记录入口。用户打开入口后才检查当前网址的草稿与待确认命令库。检查只使用已存在的数据库和只读事务，缺库为空，无法发现、库版本或结构不符、打不开和读取失败按实际错误显示。旧库不创建、不升级、不写入。损坏记录不影响有效记录查看。

与当前作用域相同的记录留在现有业务恢复流程。其他作用域须核对数据库主键中的网址、环境和数据代次，同时核对记录信封。旧版草稿和命令标记为未绑定。旧记录不按数字业务 ID 关联当前需求，不进入应用或重放流程。

列表仅含草稿版本、更新时间或命令键、动作及待核状态。草稿在用户选择后重新按原库及原键读取，并用现有草稿文本与区块校验器核对。内容以纯文本查看和下载，注明环境与代次或未绑定。命令不展示请求正文，不触发结果查询或下发。关闭入口清理当前页面持有的预览。
