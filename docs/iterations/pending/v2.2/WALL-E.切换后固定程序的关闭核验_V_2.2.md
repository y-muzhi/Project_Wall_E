# WALL-E V2.2 切换后固定程序的关闭核验

2026-11-21。实施细化，对应 V2.01 后端 4.11、7.4.1、7.10。部署已选为新的固定程序，原维护和外发冻结仍生效。新版通过 `serve-release-check` 取得同一稳定锁，以原业务只读应用核验实际选中元组。

- 受保护的核验规则绑定原维护操作、新安装锚、前后元组记录及控制摘要、预定 run ID。新程序复核固定程序、静态产物、Schema、配置和控制，保持数据库身份。无 SQLite 侧文件时以不可变方式读取，核对完整性和停写时的逻辑内容摘要，再允许读需求、文档及历史。
- 使用原运行目录下独立的 `walle-check.sock`，权限为 0600，普通入口仍关闭。继续使用恢复模式的请求权限检查。只读核验无 Worker、调度和外发，亦不创建正式业务验收数据。核验只在已绑定的原控制生效期间可用，失锁、配置或控制变化、数据库替换及出现侧文件立即阻断。
- 成功核验后仍保持 CLOSED。后续需独立采集实际进程、协议与目标能力的回执，然后才允许对原操作确认重新开放。
