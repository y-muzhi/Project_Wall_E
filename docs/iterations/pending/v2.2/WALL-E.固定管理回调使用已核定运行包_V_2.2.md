# WALL-E V2.2 固定管理回调使用已核定运行包

依据 V2.01 后端 4.6、4.11、4.12.3、7.7 和 8.2。受信宿主辅助进程先用 `setpriv` 切至管理服务身份，再调用私有管理入口。原调用以宿主 Python 运行入口，入口却直接按固定 Python／SQLite 校验当前进程，会拒绝实际宿主调用。

R145 对已注册的内部管理回调在标准宿主引导进程与固定包进程之间执行明确交接，沿用固定包摘要、私有临时根、唯一本机身份和原标准输入／输出。固定包进程继续按现有方式校验 Python、SQLite、目录和已安装程序。直接使用其他解释器、待核对版本或未受理操作仍不能进入。这一交接同时用于原发布、备份、恢复及归档的受信回调。
