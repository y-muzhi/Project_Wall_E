# WALL-E V2.2 同结构兼容凭证的独立生成

2026-11-21。实施细化，对应 V2.01 后端 4.11、7.10。现有 R26 停写预检读取与最终候选清单绑定的兼容凭证。凭证应从实际安装和已固定的候选草稿生成，且候选准备可先于任何维护停机。

- `record-release-compatibility` 接受现有受保护安装锚、原固定运行包及专用规则摘要。读取原普通用途的程序、配置、运行时和 Schema 引用；核查草稿清单及应用／前端完整索引、目标程序快照和目标 Schema。两端的精确 Schema 合约须相同，当前仅支持普通文档与命令结果范围。
- 凭证绑定源真实固定程序、配置、运行包与 Schema，绑定目标 release ID、应用和前端索引、目标程序、运行包及 Schema，并保留要求能力。目标草稿清单不包含本凭证引用，避免摘要循环。最终候选清单录入 `{ref,sha256}` 后，R26 重新核验各项并核对当前停写来源。候选独立检查、平台准入和目标配置核验仍按原流程执行。
- 输出在新受保护目录的独立固定文件，通过排他创建并重新验读，同键同字节可取回，冲突保持原事实。只读原安装与候选草稿，流程无应用启停、业务数据、候选登记或切换效果。
