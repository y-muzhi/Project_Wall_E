# WALL-E V2.2 受管普通进程观察

2026-11-20。依据 V2.01 后端 4.5、4.6、4.8、7.9、8.2 及前端 5.5、5.7。作为受管启停的前置单元，先验证服务组、实际资源和应用原运行的对应关系。

- 管理宿主以受信选择记录固定环境候选、原启动操作、run、启动回执摘要、原系统服务调用实例、固定启动器及 systemctl 摘要和容量限制。观察只查询该精确 systemd 服务，不扫描端口或进程名。
- 运行态同时核对当次 boot、systemd InvocationID、MainPID、cgroup v2 的整个进程集合与限额、实际可执行文件及启动参数、原稳定数据库锁。使用 PID 文件描述符复核进程存活。在上述事实成立后，从原 Unix 套接字核对同一进程的应用握手，单独表示是否已就绪。
- 只有同一原运行已经过真实服务组核对，且服务组无存活进程、原锁已释放、套接字已消失、持久控制仍指向本次原部署及关闭事实时才显示停止。活动状态、退出码或监听端口均不单独证明停止。
- 原证据以受信目录内的最新观察和原启动标识保存，公开投影仅返回观察时间、运行态、实际可核对 run 及原因。不返回 PID、服务配置、目录和本地凭据。过期／换 boot／来源无效按未知处理。
- 观察不会启停服务、增加额度或接管未知进程。自动受理 START／STOP、容量预留和生产维护仍需继续验证受信的执行与收尾路径。
