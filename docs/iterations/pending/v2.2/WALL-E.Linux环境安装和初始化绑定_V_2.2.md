# Linux 环境安装和初始化绑定 V2.2

2026-11-20。V2.01 后端 3.2、3.6、4.1、7.2、7.8 的 P1 实现细化。原设计与正式规格不变。

- 受信安装根由操作者明确核对。每个环境的只读安装记录登记配置字节摘要、运行包及结构资源、进程身份、稳定锁和各目录 inode。安装根只创建新环境名及 UUID，环境身份由安装操作生成；若同名安装中断，保留已建立的目录供核对。
- 首期本地单盘布局注册 Linux ext4 的各用途目录，严格拒绝目录或文件链接、权限和挂载变化。维护人与应用使用不同 UID，同环境共享专属数据组。初始化意图及进度由维护身份保管。锁文件与其目录保持 root 所有，应用和维护通过组读取、获取记录锁。不同环境的 UID 和组分别配置。
- 初始化操作包使用安装登记的维护根和原 UUID 定位。新请求、接续和只核对为明确不同动作。未知新文件归属不得自动采纳。事务提交后的恢复只依据重开验证和原回执推进。结束时控制仍为 CLOSED／NORMAL_STOP，无外发许可。
- 本实现支持 P1 的工作区快照与普通文档能力。安装端保存策略固定引用；入口的 HTTPS、客户端能力核对以及源代码快照与前端资源的产品启动检查随 B/C 接续。生产、管理恢复和非 P1 许可沿原设计依赖推进。
