# WALL-E V2.2 工作区与集成输入核对

依据 V2.01 后端 4.6、4.7、6.5 和 7.9。M2 先核对受信安装登记列出的外部开发 worktree、集成 worktree 与明确提交。工具仅允许读取固定 Git 元数据和对象，校验实际仓库、分支、worktree 双向关联以及选定完整 commit 和 tree。由原低权限开发身份运行，不触发 Git 写入、网络、钩子、过滤器或仓库脚本。

验证报告的固定提交及 tree 只说明本次所核实的 Git 对象。工作区内未提交内容与交付分开；工具不会同步文件、推断修改已经集成、登记验收通过或生成发布包。后续管理 API 按 4.7 将负责人指定的来源组合、目标 commit、资源和检查证据保存为原交付记录。本单元的离线核对使用固定且受信的登记输入，不接收外部用户直接指定的绝对路径或任意命令。
