# WALL-E V2.2 固定发布候选文件核对

依据 V2.01 后端 4.11 和 7.10。R1 先实现固定发布清单和两份完整内容索引的只读核对。候选来源为受信外层登记的清单摘要。核对实际宿主架构及固定运行包、清单协议、索引字节、应用与静态文件成员、字节长度、权限、摘要和文件系统保护。构建或变更必须形成独立候选目录。拒绝重复路径、替换、符号链接、额外文件和缺少文件。

本单元只产生候选文件完整性结果。管理登记后续需关联实际交付 commit、Schema、外部资源、适用性及独立检查证据，才可进入受管候选验证。尚未提交 Git 的 V2.2 开发副本本轮不登记为正式候选。验证的文件命名和受信登记索引仍保留在独立迭代中。
