# WALL-E V2.2 受管备份的原派发与核验

依据 V2.01 后端 4.10、4.12.1、4.12.3、6.5 和 7.10。沿用现有 BACKUP 计划、原操作、SQLite 一致捕获和封存核验。

- 受信宿主先只读取得原备份授权并核对固定捕获策略。首次领取及本地派发记录必须通过原源安装的稳定锁、当前正常关闭证明及宿主共享准入。登记事务重查原计划、当前授权和同一摘要，拒绝已撤回或已变化的操作。捕获命令在锁释放后沿原作用域执行，并按自己的锁和宿主准入保护 SQLite 写入。
- 校验错误或宿主先冻结时，未领取的操作可继续按原键核对或撤回。已领取而回执不完整时，保留原操作和原授权。相同意图重试复用原计划、备份编号和已落盘事实。原捕获无完整回执时沿现有待核实规则。
- 验证封存包及本地或异机核验时，只读取已领取的原授权和已验捕获凭证。提前调用完成命令不领取备份，也不创建备份执行目录。当前业务来源不必再次停机进行已封存资料的核验。正式恢复点仍按原 LOCAL_VERIFIED／OFFHOST_VERIFIED 条件归档。
