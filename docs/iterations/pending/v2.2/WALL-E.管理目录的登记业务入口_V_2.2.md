# WALL-E V2.2 管理目录的登记业务入口

状态为实施补充。依据 V2.01 后端 6.3、6.5 和前端 5.8 已登记环境的管理详情。原设计文件保持原字节。

受信安装方核对每套业务的独立入口后，在受保护且以摘要固定的 `management-catalog.v1.json` 中登记可选 `business_entries`。键为环境 UUID，每值只含 `data_generation`、`deployment_id`、`configuration_sha256` 与 `origin`。只在活动、已准备的管理记录与该绑定一致时投影为 `business_url`。登记可见性沿原管理读权限。配置、数据代次或部署改变后，需要重新登记匹配记录；旧条目隐去。

业务入口采用 HTTPS 来源，可带明确端口。同来源不得为两个环境或管理服务使用。目录登记独立于运行观察及业务认证。管理页在新标签打开登记根地址，保留原管理页，不传来源页、凭据、业务正文或原键。缺少匹配入口时只显示未登记。
