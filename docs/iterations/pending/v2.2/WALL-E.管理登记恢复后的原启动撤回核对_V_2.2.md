# WALL-E V2.2 管理登记恢复后的原启动撤回核对

依据 V2.01 后端 3.5、4.6、4.8、4.12.3、7.9。原管理已经记录启动撤回的终态时，关闭态新登记仍核对其原宿主范围。复用已有启动／撤回控制、实际退出结果与稳定单元命名。

- 只有原 START 已取消且原取消标记有效，原步骤、唯一 CANCEL 控制、已登记的步骤类型和原回执终态匹配，才可对已结束的辅助步骤按原单元范围查证。准备阶段同时核对原准备和运行组，实际启动后的撤回核对同一原运行组。
- 原组仍活跃、未知、无法证明空或原取消关联不全均保留阻塞。当前环境即使有另一组已登记运行也不能替代原撤回组证据。原取消账本及控制回执保持独立只读。
- 终态撤回仍残留的额度为单独需要复核的资源，不能按一般在途保留自动通过。历史仅有未派发撤回且没有外部启动凭证时按已有原路径处理。
- 本批只核对已证明完成的旧撤回；原撤回仍在途或没有可靠原效果的状态继续阻塞，交由原控制核对路径。

R133 已在 Windows 隔离验证准备阶段、已进入启动阶段、旧组复现、无法观察、重复或错用控制及遗留额度反例。原生宿主独立复验。见 [R133](../../../verification/v2.2/local-registry-cancelled-start-r133-2026-11-22.md)。
