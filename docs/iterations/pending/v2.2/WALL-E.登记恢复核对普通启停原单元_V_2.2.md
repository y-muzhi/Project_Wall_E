# WALL-E V2.2 登记恢复核对普通启停原单元

依据 V2.01 后端 3.5、4.6—4.8、4.12.3 和 7.9。固定普通 START 派发请求记录受限运行资源、宿主启动期及目标配置、部署、数据代次，登记代次由原管理操作与宿主开始记录承载。

- R144 以原封存操作、派发输入及准确定名定位原准备与应用单元。原 START 已结算且应用仍存活时，核对原准备结果、原开启结果、受保护运行策略与当前观察。其他运行不得代替原单元，历史 STOP 及已撤回步骤所指单元仍存活则阻塞。
- 只读取原管理记录、原宿主凭证和现场身份。宿主事实缺失继续暂停，由原事实及原控制途径核对。没有新启动／停止，不把原终态改写为本代次状态。
