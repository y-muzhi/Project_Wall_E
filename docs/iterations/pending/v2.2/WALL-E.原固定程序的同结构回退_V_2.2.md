# WALL-E V2.2 原固定程序的同结构回退

2026-11-21。实施细化，对应 V2.01 后端 4.11、7.10。旧固定发布清单不能追加以后才产生的兼容引用。R37 增加对同一环境直接前一固定部署的明确程序回退入口。选它必须使用新维护操作及当前真实数据。

- 回退规则单独固定，指定实际当前安装及其直接前一固定安装的精确锚、旧固定发布包和独立生成的同 Schema 凭证。核对原锚、原配置、程序、前端、平台、运行包、Schema 及前后归属，保留旧固定包字节。原普通候选仍须在其清单携带兼容引用。
- 当前环境重新关闭，核对当前 SQLite 与最近一致恢复点及真实恢复证据，不能引用上次发布前的数据。为旧程序另准备一个全新部署 ID，继承当前环境、数据代次、数据库和稳定锁。选定旧程序后继续原关闭核验、公开入口及开放协议。
- 当前仅接直接前一固定部署的 SAME_SCHEMA，历史任意版本、配置重建、数据换代和生产采用继续分别验证。
