# WALL-E V2.2 固定资源目录的重复结构核验

日期 2026-11-26。设计来源为 V2.01 后端 4.1、4.12.2、4.22.2。记录仅用于本轮实现及验证，正式规格保留原版本。

恢复完整核验观测到应用取得稳定锁并绑定套接字，尚未完成 ASGI 启动。复核资源加载器发现 v8、v9 依各自 Function 配置使用同一个已钉扎的传输 Schema 和标准输入 Schema，现有加载器对同一版本文件重复做结构检查。

在一次固定 v8 资源加载中，同一文件的严格解析、Draft 2020-12 元结构及项目 Schema 检查各执行一次。缓存仅覆盖同一次加载中的独立已核验文件，作用域在该加载过程内。每个 Function 的上下文、提示词、预算、序列、原协议与扩展兼容检查仍分别执行。原清单、每份实际资源的文件长度和 SHA256、不同资源各自的严格校验及失败行为继续保持。任何未知或损坏资源不得进入应用。普通应用和恢复应用继续共用同一个资源加载器。

验收用固定 Linux 解释器分别在独立进程运行原和当前目录加载，核对实际已装配模板、Function 和 Schema 的同一内容及拒绝行为。端到端恢复仍以原应用、稳定锁、Unix 对端、安全退出和持久回执为准。
