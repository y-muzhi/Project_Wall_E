# WALL-E V2.2 独立管理只读入口

依据 V2.01 后端 6.5、7.9 及前端 5.5、5.7、5.8、6.2。M5 将已登记环境、受信工作包、原操作、交付凭据及现有资源投影到独立管理页。身份和管理作用域使用独立的入口配置、握手和响应头。以当前管理角色和登记的可见范围过滤所有列表、详情和原键。页面严格按照服务端字段渲染；没有宿主容量或实际运行证据时分别显示待核实。

固定静态产物与已有业务前端独立构建。在专用 HTTPS 入口的回环端口 9444 通过独立账号及受保护 Unix 套接字访问。网关负责认证和重写可信主体，管理程序复核来源、身份、管理作用域及操作权限。只读管理页可以与受信本地登记并行读取一致的 SQLite 快照。M5 界面只开放已实现的读取动作。带写入的浏览器命令、受管启停和维护另按设计接入原命令存储、准入、回执和实际资源观察。
