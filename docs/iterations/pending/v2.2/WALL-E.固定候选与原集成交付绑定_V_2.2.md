# WALL-E V2.2 固定候选与原集成交付绑定

2026-11-21。依据 V2.01 后端 4.7、4.11、6.6、7.9、7.10。R4 只核对来自受信安装目录的固定候选。目标状态为已封包，独立候选运行和发布准入分别验收。

- 在固定管理目录新增可选候选索引。每份候选由管理员固定引用原成功集成交付、不可变发布清单、真实 Schema 目录与独立构建事实。发布清单逐文件核对继续复用 R1。
- 原集成交付和每条开发来源在当前登记代次按原操作查验，绑定具体 Git commit 与 tree。发布清单的源码 commit、资源引用、运行包、平台和 Schema 都须逐项吻合。构建事实另外绑定两份内容索引摘要，无最终清单摘要循环。
- 受信管理程序对每份候选的 Schema 来源摘要使用该候选应用索引内的实际固定源码及设计，保全冻结的原 Schema、结构核对和运行包约束。维护兼容核对原安装和目标候选各自的源码摘要，再比较结构契约。校验器只读目标字节，无需加载目标程序代码。
- 按登记参考重新核对实际资源文件。返回只读候选核对明细，无实际代码合并、Git 提交、生产更新、自动发布或重新打开。
- 核对通过不自动提升为独立候选验证通过。运行用例、浏览器、数据恢复和目标平台的实际验证分别由 R5 及维护签入支撑。
