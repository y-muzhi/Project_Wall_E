# WALL-E V2.2 管理原发布操作与宿主维护绑定

2026-11-21。依据 V2.01 后端 3.5、4.10、4.11、6.6.2、7.9、7.10，接续固定发布预览。

- 固定宿主工具从同一受信管理库领取已确认原操作，事务内先记同一操作派发标识。对同一原 ID 重取该归属。之后才以原环境维护身份执行已有停机维护入口，使用准确源安装、程序、原控制版本／摘要和同一原 ID。原动作的目标配置及候选由固定计划绑定。
- 宿主操作前核对当前数据文件身份，已有原维护时以同一原意图核对，关闭后将独立持久回执绑定原管理计划和实际版本。失败、超时、部分结果均保持原操作可核对，管理端不把未验证副作用视为成功。
- 关闭范围停止于原维护。有价调用、切换和应用启动仍各按后续实际准入。宿主步骤只能经固定本机入口发起。
