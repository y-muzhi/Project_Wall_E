# WALL-E V2.2 管理站的原控制查询与核对

2026-11-21。依据 V2.01 后端 6.5.2、6.5.3、7.9，前端独立管理站的原结果恢复规则。

- 加入原操作下按 control_key 查询回执，校验管理范围、原操作、控制归属和主体。只读取原回执及当前原操作，回执内容保持不变。
- 管理 API 的控制写入先开放 RECONCILE。仅观察原效果，按原作用域、原操作和控制键登记独立回执，与原操作状态共用事务。相同键重复可直接重取，绑定冲突和陈旧操作版本拒绝。
- 管理页可显式查询原控制回执。网页暂不派发控制写入；浏览器原控制意图持久化及恢复接续后再考虑开放。继续、取消和宿主外部动作边界仍由已有受信入口控制。
