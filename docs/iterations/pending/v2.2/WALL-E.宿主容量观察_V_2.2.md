# WALL-E V2.2 宿主容量观察

2026-11-20。依据 V2.01 后端 4.8、6.5.2 和前端 5.5。容量观察、管理额度和每个原操作的资源占用分别表示。

- Linux 固定程序从内核 `/proc/meminfo` 有界读取唯一的 `MemAvailable`，以字节表示，观察时间取本次成功读取完成时。普通宿主启动准入和管理读取使用同一个解析器。读取失败、值格式错误、来源重复或越界时返回未知，实际观测到的零仍是有效数字。
- `GET /management/api/v1/capacity` 的 `available` 在 `HOST_MEMORY_OBSERVED` 时表示采样的宿主可用内存字节数。无法核实时，`available` 和 `observed_at` 同时为空。等待数仅统计当前查看者有权看到的原操作。
- 页面以 MiB 显示实际采样，独立保留管理额度和管理预留的未知状态。额度还需受信规格和聚合占用事务。观察成功本身不会受理、排队或派发启动，也不判断已有运行可以释放额度。
