## 接入与验收

- 从现有「新建文档 → 前端／后端设计文档 → 固定框架」生成完整的 Markdown 填写说明、章节和表格。采用同一资源键的新 `framework-v2` 身份，新版本引用能追溯到对应完整正文。章节、表格和填写内容在既有编辑路径可修改。
- 空白创建继续为空并记录类型。保留 `framework-v1`、`blank-v1` 及历史通用文档原识别和解析，旧文档与旧请求按原资源版本回读。AI 写入沿现有资源引用提供职责、章节和填写规则。
- 验收使用隔离 HTTP 创建、读取、重放及旧模板回放，检查 Markdown 章节和表格。发布到现有 8001；涉及后台进程切换先核对在途运行和业务占用。真实模型、计数和业务样本文档写入不属于本轮验证。
