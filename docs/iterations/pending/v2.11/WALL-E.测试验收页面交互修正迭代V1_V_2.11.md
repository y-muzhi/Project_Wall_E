# WALL-E 测试验收页面交互修正

2026-11-24 · V2.11 事项 16 · 待合并。截图反馈指出测试任务目录的页头、工具区、筛选和分页没有对齐项目规则。以 V2.0 前端 §5.1、BND-TEST-LIST、BND-TEST-CREATE、BND-TEST-PLANS 和 V1.5 SHR-UI 为依据，沿用上轮已完成的工作台样式。代码基线 `cd48227` 加事项 15 工作区。

| 范围 | 修正规则 | 验收 |
| --- | --- | --- |
| 页面外壳与工具条 | 测试任务、任务详情、计划资源、设置采用共享页头。内容使用导航外剩余空间，标题和正文共享边距。新建使用主按钮；相关导航与其他操作按原权限提供，窄窗流式换行。 | 核对四个路由；1024／1280／1920 及窄窗，按钮文字和焦点可见。 |
| 任务筛选及状态 | 状态／用途复用 SingleSelect，需求／文档字段标明数值 ID。筛选操作并排、字段错误就地展示；保留显式应用、清除、页码归一及已固定的来源筛选。首次失败可重试，切换失败保留最近成功列表。 | 键盘选择、取消、应用、清除，空态、失败恢复、翻页与旧结果。 |
| 列表及分页 | 任务行用 RecordList，业务空态由 EmptyState 呈现。测试模块分页统一使用 Pagination 和真实接口元数据。第 1 页零记录不展示分页；越界给出有效页恢复入口。 | 正常列表、多个状态、有数据翻页、过滤零条、空目录、越界；计划与详情相关分页沿用各自数据源。 |
| 新建入口 | 使用原抽屉和公共模态焦点机制。关闭回原入口，保留原草稿和提交限制。 | 实际打开及 Esc／取消，核对不可提交提示。 |

本轮改动针对测试模块的交互外壳、目录、分页和新建入口。验证使用当前页面只读入口与隔离响应。测试执行、后台业务、静态服务发布按各自授权执行。

## 实现与证据

四个测试路由已共用页头与页面边距。测试任务目录使用公共选择器、记录列表、空态与分页，其他 Testing 分页直接读取完整 API 元数据。新建抽屉采用公共模态注册及焦点环。已在实际 5174 与隔离响应中验证，8001 静态入口尚未更新。[验证记录](../../../verification/v2.11/testing-interaction-2026-11-24.md)
