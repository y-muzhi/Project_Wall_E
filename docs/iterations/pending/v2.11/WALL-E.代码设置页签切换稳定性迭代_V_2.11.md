# WALL-E V2.11 代码设置页签切换稳定性

2026-11-26 · 代码设置

用户报告仓库、执行配置、检查配置和授权之间切换时页面闪烁。现有路由在同页切换时仍将窗口滚动归零，公共「待核对操作」也随着分区读取暂停并重新开始。两个分区内容高度不同时，桌面滚动条可能改变内容定位。

- 切换分区时保留代码设置页和待核对卡片，保留可用的当前滚动位置，并为经典滚动条预留稳定空间。刷新页面、浏览器前进后退仍可恢复 URL 指定的分区。
- 会话首次进入、返回前台、恢复网络和主动点「重新核对」时继续获取原请求结果。切换分区只更新该分区负责的内容。
- 验收覆盖宽屏和窄屏入口、初始读取及无记录、已有记录和错误反馈、浏览器历史与频繁切换。检查采用只读操作。

## 实现和验证

`ApplicationRouter` 只在离开或进入代码设置页时归零窗口滚动。各分区继续沿用原有路由参数和历史记录。公共「待核对操作」的读取跟随设置页生命周期，各分区的读取跟随所在视图。经典滚动条在代码设置页预留空间。

8001 旧版的执行配置切到检查配置时，滚动从 45 px 跳到 0 px。新版通过四个分区来回切换、浏览器前进后退、窄屏下拉，以及公共核对区域节点和加载态稳定性检查。已有记录、错误保留、恢复并发由原核对读取专项覆盖。详见[验证记录](../../../verification/v2.11/settings-and-review-tabs-2026-11-26.md)。
