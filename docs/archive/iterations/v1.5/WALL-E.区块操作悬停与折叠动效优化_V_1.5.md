# 区块操作悬停与折叠动效优化

> 2026-10-31归档：最终规则已按原章节合入[前端设计](../../../design/v1.5/WALL-E.前端设计文档_V_1.5.md)，具体位置与替代边界见[合并记录](../../merges/v1.5/合并记录-2026-10-31-近期交互归并.md)。下文“待合入”“本轮”等保留原阶段事实；历史验证不改，归档不等于产品验收。普通归档增加此提示并重定位链接，不是字节原样副本。

日期：2026-10-30。编号：M15-FOLD-UX-02。用户截图及三项要求：对齐正文六点／折叠按钮、避免按钮与区块背景重叠；菜单只在按钮／菜单悬停范围内展示；改善折叠与展开动效，复用或新增公共方法。

依据：正式FE1.0／EFFECTIVE BND-EDITOR／SHR-UI／SHR-MOTION、BE原文档身份及只读呈现边界，承接M15-SECTION-FOLD-01、M15-BLOCK-MENU-01。正式设计摘要沿当前断点已记录基线。本轮已读导航／标题范围、编辑保护、来源及评论调用、公共动效和关联离线专项；无关AI／HTTP章节未重读，不改正式设计／冻结资源。

输入／输出／不变量：真实区块与标题ID、首行排版、可见视口、折叠集合、指针／焦点状态进入原DocumentNavigation；输出按钮位置、菜单可见性和章节呈现。不修改正文节点属性、正文版本或业务数据；隐藏内容立即受原编辑保护，最终正文／大纲状态仍由同一导航owner决定，不能用动画计时延后业务状态。

实施顺序：统一两按钮实际24×28尺寸与首行中心及独立沟槽 → 菜单悬停进入／离开与跨隙关闭、保留键盘可达 → 公共实测尺寸折叠动画及中断／减少动态效果／销毁清理 → 必要离线、类型／格式及临时构建 → 同步映射和断点。

规则：按钮与正文高亮保留可见间距，六点和箭头同排；按钮悬停使用独立中性底色。鼠标进入六点按钮才显示菜单，移动进菜单可操作，离开两者即收起；短暂跨隙宽限避免途中消失，点击不锁定菜单。键盘ArrowDown／激活仍可进入，Esc关闭并恢复焦点；来源等已打开的独立窗口保留原关闭规则。

动画：替换依赖display:none与自动高度插值的旧呈现，通过公共方法采样实际高度、边距／内距及透明度，用像素关键帧平滑变化；快速反向先采样当前显示尺寸，不从头跳播。减少动态效果、能力缺失、视口改变、文档切换／销毁均可靠落到最终状态，帧／动画／监听不残留。继续使用外置作用域样式及Web Animations，不向ProseMirror节点写class/style。

本轮仅前端实现及必要检查，不操作用户名称／正文／数据库，不启停用户服务，不调用模型／计数，不提交推送。已有选区、折叠及名称改动均保留。浏览器证据以实际可用工具为准，不能以离线结果冒充视觉验收；本轮不重试上一轮被停止的Windows UI链路。

最终接入：shared/disclosure-motion.ts承载采样／批量几何读取／WAAPI及清理，继续使用SHR-MOTION的内容180ms及原缓动；documents/section-folding.ts负责作用域显隐和瞬时交互保护，删除旧自动尺寸／display插值和计时器。navigation.ts共用blockControlPositions，navigation-view.tsx负责120ms跨隙关闭、键盘／触摸及焦点清理，styles.css统一按钮实际尺寸与中性底色。正文CURRENT／人工草稿／历史及大纲切换仍由同一导航实例接入该公共折叠路径；没有第二套折叠状态。

公共方法契约：DisclosureTarget为element:HTMLElement＋collapsed:boolean；DisclosureMotion.run(targets,moving,moved,enabled=true)只管理视觉轨道。moving(true)要求所属呈现层暂时暴露自然尺寸，moving(false)应用最终显隐；moved用于重新测量按钮／标记位置，不是业务完成事件。finish立即应用最终呈现、取消全部动画及RAF；dispose另清理媒体／窗口监听并退役实例。业务折叠集合和隐藏编辑保护仍由DocumentNavigation立即更新；不支持interactivity:inert的正文呈现即时落位，不留下不可见但可编辑的过渡内容。该方法是原BND-MOTION职责内的尺寸动画实现补充，尚待正式归并。

状态：三项前端实现完成，无半成品或未接调用方；438项前端离线及最后13项定向复验、类型／格式／临时构建通过。原计时器断言失败与替代、新动效边界及未执行浏览器见[检查记录](../../../verification/v1.5/fold-hover-motion-2026-10-30.md)。正式设计归并与视觉验收仍待后续，不能以本项覆盖原未验证事项。
