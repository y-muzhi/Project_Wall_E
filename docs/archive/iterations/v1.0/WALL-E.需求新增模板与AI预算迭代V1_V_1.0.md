## 1. 原因与采用范围

原“需求新增”使用`new-requirement@v1`，正文为简短章节及“待确认”。本次新建需求改用项目内统一需求规格说明完整模板，保留全部章节、表格、占位符、填写说明和条件小节。源文件及旧采用资源不改写。

采用副本为`backend/resources/v3/templates/new-requirement.v2.md`，按原始UTF-8字节复制，共85,865字节；实际Markdown解析产生50个标题，标题级别与纯文本登记在同版本元数据中。新建入口的模板名称为“统一需求规格说明（完整模板）”。选择“需求新增”后仍按原单一可用模板规则自动选择；“需求改造”保持原`change-requirement@v1`。

新模板是本次确认来源的固定快照。以后修改`docs/templates/`中的编写模板不会静默改变已经创建的需求，需发布新的采用版本。

## 3. AI上下文预算

仅`new-requirement@v2`对应需求的新AI运行使用Function v3及计数策略v4。旧模板对应新运行继续使用原默认Function v2；已存在运行继续按持久化的Prompt／ContextTemplate版本恢复。普通文字继续等待任务不换冻结版本；初始化卡片新运行、评论修改和失败重跑按当前需求固定模板选择对应策略。

| 预算项 | 原预算，token | 完整模板预算，token |
| --- | ---: | ---: |
| 模板分项 | 4,096 | 65,536 |
| 输入总量，含封装余量 | 24,576 | 131,072 |
| 输出上限 | 8,192 | 8,192 |
| 输入＋预留输出总量 | 32,768 | 139,264 |
| System协议 | 4,096 | 4,096 |
| 当前用户输入 | 4,096 | 4,096 |
| 指定来源 | 4,096 | 4,096 |
| 历史分项 | 2,048 | 2,048 |
| 经验封装余量 | 1,024 | 1,024 |

模板预算用于序列化后的整个template对象；输入总量还包含CURRENT读取区块和元数据。完整模板同时存在于template和CURRENT中，不能只提高模板分项而保留原24,576输入上限。因此本次同步提高这两项，总量严格等于输入上限加输出预留。其余分项、单次输出、精确模型、请求参数、超时和每逻辑调用最多三次Chat尝试保持原契约。

本次选择的本地上限低于供应方为精确模型`deepseek-v4-1-flash-260910`列出的1024k上下文窗口与最大输入；容量依据见[火山方舟官方模型列表](https://docs.volcengine.com/docs/ark/model-list?lang=en)。本地预算不是供应方容量或真实费用保证，实际发送仍须重新精确计数。
