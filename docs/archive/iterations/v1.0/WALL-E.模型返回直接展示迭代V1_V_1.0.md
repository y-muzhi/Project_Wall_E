## 2. 当前采用规则

模型返回展示不依赖整份输出Schema、逐字卡片等价、证据引用或问题去重检查。合法结构继续使用卡片、检查结果、建议等既有展示；不能识别、字段多出、非JSON、截断、拒绝或工具式内容等返回，保存并显示实际助手原文。显示不修改返回原文，也不补造用户选择或模型内容。

取消生产路径的已回答问题重复拦截；卡片message可为说明，与cards独立显示。初始化推进提示仍提供指导，但不以是否遵循指导决定是否显示。保留旧冻结资源字节，旧提示词中的格式要求不再是拦截返回的运行规则。

收到实际助手返回后，不因输出格式、重复提问或自动写入不成立而再请求模型。仅尚无助手返回的网络失败沿既有重试策略。返回用量异常仍记审计，不能吞掉已经收到的内容；请求前预算、计数和许可不改变。

业务操作与内容展示分开：自动写正文和创建可执行修改建议仍检查事实确认、目标、版本和模板保护；不能采用的操作不执行，其返回仍作为只读原文显示。解析／写入检查的失败事实保留，不伪造trusted_output或校验成功；“运行完成”表示本轮返回已经交付，不代表需求初始化业务完成。
