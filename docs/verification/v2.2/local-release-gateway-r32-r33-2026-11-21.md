# V2.2 R32／R33 固定候选网关装配与实测

2026-11-21。Windows 隔离实施副本。Caddy 官方 v2.6.2 Windows amd64 包经官方 SHA512 核验，解包工具不安装进系统。独立网关以 127.0.0.1:54123 监听，使用临时 CA、虚构账户、独立目录和本次创建程序，结束已停止并清理运行资料。

- 实际 `caddy validate` 和 HTTPS 验证认证拒绝、固定公开配置及配置摘要、实际目标首页、新资源、旧版专属资源回退、另一环境隔离、缺失文件和后端未启动时的 502。
- 初次真实接口回放发现公开 JSON 使用现行非 canonical 序列化。HTTP 检查允许该格式，同时拒绝重复键和错误数据。磁盘控制及证据继续要求 canonical。修正后实际网关验证通过。
- 保护索引与实际静态文件专项覆盖相同路径内容冲突、同名引用错误及原部署不符。Linux 监听进程解析使用受控 procfs 数据检查正反例。
- Windows 临时资源路径、端口和进程权限与 Linux 发布入口不同。Linux Caddy 真实 PID、procfs、稳定锁和具体两套固定环境仍待接续。
