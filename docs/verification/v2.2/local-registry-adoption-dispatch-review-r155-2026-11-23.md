# R155 将新登记已采用的目标纳入旧派发复核

2026-11-23 香港时间。V2.2 Windows 独立分支。依据 V2.01 后端 4.10—4.12.3、7.9。

- 派发复核仍使用原封存清册及原受保护宿主观察。只有确切采用授权、原正常停止、所选管理入口、相同目标控制、数据对象和原运行单元全部相符时，才按当前目标核对该环境的声明，并确认同一原步骤已通过独立结算。
- 使用实际原 RESTORE、原 SQLite 声明和 Schema 5 采用回执，验证符合条件的已停止目标可清除对应阻塞。目标数据库身份漂移、其他环境未核实、原声明身份漂移和最新现场与封存观察变化仍阻断派发。
- 对不同的原开放回执、组占用及其他环境保留逐项回归。Windows 用适配方式读 Linux 文件／组事实；本记录包含实际采用回执和稳定原／新文件，原生 Linux 待验。
