# V2.2 R329 Unix ATTACH 描述符原型

2026-11-24（香港时间）。在无网卡 Ubuntu 24.04.5 x86_64 的独立来宾中，沿 [R323 的逐消息核验](local-x86-unix-control-peer-r323-2026-11-24.md)，使用三个专属非 root 假角色，无业务库、真实数据、模型或用户进程。

- 对有原连接身份和原请求的成功应答，内核实际传入一个 pidfd 副本。以 `/proc/self/fdinfo` 和持有的原描述符核对原测试运行对象。重复报文只携带同一原引用，未发出额外任务或创建新对象。
- 其他请求键、同报文两个描述符、普通文件描述符、另一仍活进程的 pidfd 均拒绝。每条消息之后核对描述符清单，收到的副本关闭且不可继承。连接退出后假角色正常回收。
- 五个实机用例通过。应用的正式 ATTACH 请求资格、原任期和幂等、已退休原运行及联合平台验证仍待接续。
