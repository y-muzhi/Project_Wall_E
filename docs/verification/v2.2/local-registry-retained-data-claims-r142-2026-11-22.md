# R142 登记恢复的原数据代次保留声明

2026-11-22 香港时间。V2.2 Windows 独立分支。依据 V2.01 后端 3.5、4.12.2、4.12.3、7.9。正常恢复保留旧数据声明并注册新根和数据库。恢复登记从当前固定准备凭证沿数据库身份回溯，只有位于原环境稳定根下且测得身份与原声明吻合的旧数据可判为保留。另行准备的目录、缺凭证、别名和数据库替换继续阻塞。

- 38 项固定 SQLite 与派发专项通过。专项含两次恢复的凭证链、缺失、无关联准备、代理别名、旧数据库换表位的反例。
- 实际 RESTORE 从同一独立管理库读取新旧四项声明。真实原数据库和新数据库分别测得，状态为两项 BOUND 与两项 PRESERVED。替换原数据库文件使旧两项为 CHANGED，原件复位后恢复。实际普通文档保存与重启仍通过。
- 读取业务数据库文件的身份及受保护准备凭证，保留原文件内容。开发验证适配 Linux 文件描述符、权限、挂载和宿主进程。真实 ext4/systemd 下原数据不可访问仍需 ARM64 原生联验。
