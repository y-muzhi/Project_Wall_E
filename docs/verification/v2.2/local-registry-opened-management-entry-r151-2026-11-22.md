# R151 确认所选管理入口解析原正常停止的目标

2026-11-22 香港时间。V2.2 Windows 独立分支。依据 V2.01 后端 4.10、4.11、4.12.3、7.9。

- 固定 `verify-registry-recovery-deployment-entry` 从受保护清册和开放、停止回执确认同一目标。按已确认网关加载所选管理目录，核对目标候选、程序、业务入口的数据代次／部署／配置、管理员及当期运行容量政策。结果包含可重算、可精确绑定的摘要。
- 沿真实管理 RESTORE 和原暂停后正常停止的测试应用，通过固定候选和所选管理目录的读取。仍在运行、网关配置漂移、已核准目录仍指旧数据代次、候选安装索引缺失、容量政策漂移均拒绝；恢复独立测试文件后读回相同核对。原登记、运行声明和暂停保持。
- 回环 Windows 验证使用 Linux 文件身份和停止观察适配。跨代次运行许可、实际管理采用、Linux 原生和生产均未进行。
