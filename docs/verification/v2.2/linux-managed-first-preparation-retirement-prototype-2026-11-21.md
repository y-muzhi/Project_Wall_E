# V2.2 首次启动准备回退原型

2026-11-21（香港时间）。专用 Ubuntu 24.04 ARM64／systemd／cgroup v2。沿用 M21 固定运行包和 `program-m21-51c0b3ec4e7e`，初始化一个独立普通安装，以暂存脚本调用实际启动器、固定准备单元、普通应用实际使用的稳定锁和控制原子写入。该脚本只用于一次性隔离验证。

- 首次准备前，CLOSED 控制仍引用该安装的原初始化操作。真实准备组生成准备回执并退出后，CLOSED 控制改为引用原 START，同一准备版本仍生效。直接使用另一个启动操作返回 `START_RESULT_UNVERIFIED`。
- 在已知原准备 InvocationID、准备组实际退出、没有应用单元的前提下，以原数字维护身份和稳定锁对照原控制事实。错误版本在写入前拒绝。原型恢复准备前的原初始化操作 ID，将控制版本从准备版本递增一次，保持同一代次、部署、配置及 CLOSED。实际写入后模拟返回丢失，原样读到当前控制后直接返回，控制版本保持不变。
- 实际旧应用启动器按原准备回执重取失败并未建立套接字。真实新准备通过原初始化核对，得到不同 run_id 和下一版本。尝试再次执行旧回退时拒绝，未影响新准备。专用临时安装、账户及唯一单位组清理完成。
- 复验让新准备真正运行 WALL-E 至 OPEN，再仅对本轮进程组发送正常关闭信号。再次准备及回退后，实际首次开放回执及部署 ID 保留，下一份真实准备成功。独立进程组和临时套接字均消失。
- 此原型验证已经完成准备但还未派发对应应用的两个分支。管理入口尚待持久化准备前控制摘要和可信执行快照，并把物理准备组停止、控制 CAS 及原控制回执绑定。准备中止前后回执不齐及容量释放待接入验证。
