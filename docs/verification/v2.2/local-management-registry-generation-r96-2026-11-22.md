# R96 新管理登记代次的离线准备及独立核对

2026-11-22。独立 Windows 源 `output/v22-dev-isolated`。固定 SQLite 通过 Windows 文件描述符适配。离线潜在新库在原保护登记下单独发布，活动库、安装锚、原快照和业务环境不参与切换。

- 实际原 SQLite 包含操作、未知外部效果、控制回执、仍在占用的资源、两种计划和旧运行观察。使用同一原暂停摘要、原快照回执及目录摘要生成新代次。旧操作、步骤、控制回执和未释放占用保持。新库只承接已消费的历史计划，运行观察重新核对。
- 实际目标 SQLite 格式 2 使用历史代次引用和写保护。保留早期请求键，目标代次可独立使用同一键。更新旧操作及步骤、删除旧控制回执均拒绝。第二次准备保留连续三个代次及两个历史操作，原第 1 结构仍可读并验证。
- 发布后断回执按同一原策略恢复。新库核对在活动库、原目录和源快照移出测试活动路径后通过。错策略摘要、同一原号另一新代次、损坏回执拒绝。检查结束移除临时数据库及夹具，无监听。
- 新登记的正式采用、旧辅助进程与环境事实、外部计划及资源核对须继续走原宿主受信路径。原生 Linux 保护目录、固定实际进程及网关未在此专项运行。
