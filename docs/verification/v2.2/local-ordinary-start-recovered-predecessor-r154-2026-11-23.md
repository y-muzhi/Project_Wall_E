# R154 普通启动使用跨管理代次的正常停止前置依据

2026-11-23 香港时间。V2.2 Windows 独立分支。依据 V2.01 后端 4.10—4.12.3、7.9。

- 普通 `start-runtime` 的受保护策略可以引用原待结算部署的授权和采用摘要。新管理目录、派发开放凭证、原封存范围、目标配置、原停止、当前控制哈希、数据库对象及单元空闲逐项相符才可采用。没有新租约时才可首次采用，已绑定同一启动的租约按现有流程读回。
- 用实际原管理 RESTORE、真实正常停止后固定控制和 Schema 5 SQLite 回执，验证启动路径的条件核对。暂停、错误收据、错误停止、原组仍在、库对象漂移和其他启动租约均拒绝；相同租约不重复采用。
- 测试使用独立 Linux 宿主事实适配及固定开放凭证夹具，只覆盖普通 START 的前置真值；未通过最新 ARM64 启动原生单元。派发前实际采用结果的核对见下一单元。
