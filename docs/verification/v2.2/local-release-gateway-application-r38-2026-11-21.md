# V2.2 R38 网关和普通发布应用隔离联验

2026-11-21。Windows 隔离实施副本。实际 Caddy 2.6.2、Uvicorn／FastAPI、真实 SQLite。运行使用本轮临时 HTTPS CA、账号及数据库。仅监听本机 61535（Caddy）与 61536（WALL-E）。Windows 联验使用回环 TCP 代替 Linux Unix 上游，Linux 权限、稳定锁及 procfs 身份部分用测试适配。

- 先验证认证及目标公开配置。旧应用仍未监听时，业务 API 返回 502，原结果为待核对。随后实际固定发布入口所用的应用范围启动，对经同一 TLS 网关的真实 HTTP 请求返回 OPEN，正确读回原文档，按正常业务接口创建新测试需求并读回。
- 正常停止应用后，网关业务接口恢复 502，原 OPEN 证明仍可从控制读回。两个实际监听及其拥有者按本轮范围停止。证书、测试库、配置及构建输出为本轮临时目录。
- 最初两次业务链均通过，但 Windows 证书嵌套路径过长导致结束清理失败。核对两个监听已关闭后按实际专属目录清理。缩短临时证书路径后重跑，整场验证与清理通过。Linux 实机和生产未执行。
