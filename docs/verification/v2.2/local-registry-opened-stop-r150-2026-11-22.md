# R150 登记暂停期间正常停止原待结算运行

2026-11-22 香港时间。V2.2 Windows 独立分支。依据 V2.01 后端 4.10、4.11、4.12.3、7.9。

- 新建宿主固定入口 `stop-registry-recovery-deployment`。在已选择恢复、保护清册和同一派发暂停下，停止策略须绑定同一原运行、策略、受管单元和 OPENED。复用普通 STOP 核对，保持正常退出、原已派发回执只读回及无强制杀进程的限制。
- 使用本轮拥有的真实管理 RESTORE、实际普通应用和受保护式停止文件专项。错误运行键和允许强制杀进程的单元配置被拒绝。只有一个本轮应用接到测试停止并正常关闭。故意使首次停止结果无法证实，返回不确定并保留已派发；再次调用仅观察并得到同一份 STOPPED，重复调用无额外停止。
- 实际固定 SQLite 原登记和操作未改变，原运行额度和数据声明均保留。Windows 独立测试用本轮应用正常退出代替 systemctl 并适配私有目录、锁与 Unix 观察；原生 systemd 及候选采用未验证。
