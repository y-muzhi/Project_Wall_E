# R153 原开放且已停止目标独立登记结算

2026-11-22 香港时间。V2.2 Windows 独立分支。依据 V2.01 后端 4.10—4.12.3、7.9。

- 固定 `settle-registry-recovery-deployment` 从原封存 SQLite 重算已核对投影，绑定所选代次的宿主授权，只向所选 Schema 5 登记库写入原目标登记、采用结论和原运行额度释放。原操作与原步骤由数据库保护；运行当前及原保留数据声明均保留。
- 测试使用实际管理 RESTORE 正常停止后的固定证据。错摘要拒绝且无写入，故意在事务中断则全部回滚。事务提交后的凭证首次发布失败返回不确定，重试只补齐同一凭证，原快照字节、原操作、原步骤、当期和留存数据边界一致；再次建立登记副本时采用历史保留。
- 采用回执能走原历史投影。验证时派发仍按原现场核对门槛暂停。本次测试有 Windows 宿主适配，ARM64 和生产未验证。
