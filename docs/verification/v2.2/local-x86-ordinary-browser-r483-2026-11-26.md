# R483 Linux 双站 HTTPS 浏览器验收

2026-11-26（香港时间）。基线为 `codex/2.2` 和 `codex/2.2-integration` 当前应用源码，两条分支各自的普通前端构建，120 个构建文件内容一致。使用无虚拟网卡的 Ubuntu 24.04 x86_64 TCG 验证来宾和本轮临时覆盖盘。

两站均由实际固定工具完成独立安装和启动，使用各自的应用与维护 UID、共享组和独立入口组、固定 Schema、配置、数据库及 Unix socket。产品 `environment_gateway.py --site` 从两份真实安装生成双站 Caddy 配置。Caddy 只监听来宾回环 9443，宿主无端口转发。通过签发的本轮 CA 核对真实 TLS 和未认证 401，CA 仅加入独立的浏览器测试信任库。测试应用仅启用普通文档读写能力。

首个 Chrome 会话在开发站通过环境握手，看到开发工作台，并通过实际界面创建需求和空白文档。首次浏览器脚本在已创建文档后从页面主体寻找「人工编辑」，未展开「更多操作」，未进入编辑。复核产品 `requirements/header.tsx` 后按菜单顺序修正脚本。该轮的浏览器与临时服务已退出，覆盖盘和启动介质已回收。修正后在新的独立来宾中，两套安装使用分开的 Chromium 用户身份、HOME、临时目录和 Playwright 会话。Chrome 保持原生沙箱，证书校验开启。开发站、集成站均从工作台在真实页面创建需求和空白文档，展开「更多操作」进入人工编辑，填写各自的合成正文，点击「完成编辑」，刷新后读回刚才保存的正文。两侧流程均成功，来宾记录 `WALLE_QA_DONE:0`。

浏览器会话和两套服务均退出。宿主 QEMU PID 54752 已退出，覆盖盘、启动介质、浏览器配置、日志及临时业务数据随本轮专用目录回收，底层镜像大小和修改时间保持一致。Windows 8001 无本轮操作。此轮未覆盖完整 FE-01—13 矩阵、受信正式候选、目标宿主或生产采用。
