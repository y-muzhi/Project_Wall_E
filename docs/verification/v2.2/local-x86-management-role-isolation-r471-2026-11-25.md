# V2.2 R471 管理者与开发者的真实隔离读取

2026-11-25（香港时间）。从 [R470 两份真实登记](local-x86-current-management-browser-r470-2026-11-25.md) 的已关机来宾启动独立无网覆盖盘。原登记锚及两套实际安装保持，独立测试目录提供当前管理资产和只向开发者授权开发站的保护目录。真实 Caddy HTTPS 9444 仅来宾回环。

- 管理者 HTTP 读取开发与集成两站。开发者按实际身份与登记代次 HTTP 只读到所分配的开发站，原开发详情 200，未分配的集成详情 403，原操作列表也排除该集成环境。开发者身份的登记动作不可用。
- 两个独立非 root 浏览器身份各有物理独立的 HOME、临时目录及浏览器状态，并分别信任同一来宾 CA。在同一真实管理地址同时打开沙箱 Chrome，管理者仍看到两站，开发者只看到已分配开发站和开发者身份，页面无管理者的登记操作。
- 第一轮测试脚本误认为开发者页面应保留禁用按钮，实际产品对该角色隐藏登记入口。依现有前端角色判断修正验证，复跑通过。浏览器、管理应用、Caddy 和来宾有序结束，无管理 socket 或回环监听残留。
