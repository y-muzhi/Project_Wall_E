# R97 宿主恢复冻结与普通最终开放

2026-11-22。独立 Windows 实施源及固定 SQLite。Windows 适配 Linux 目录控制锁和文件描述符，SQLite、普通准备、控制及原收据使用实际逻辑。

- 从原初始状态和空白的受信新宿主根均可建立冻结。工作区正常安装的原状态不被自动替换。共享启动锁存在时拒绝进入冻结，原锁释放后按原策略原子发布。相同请求重复和只读核对一致，冲突请求或错宿主根身份拒绝。

- 无端口监听。首次夹具误用无历史回执的模拟普通关闭，调整为真实初始化证据后通过。Linux 目录锁和实际进程在专用 ARM64 待验。逐环境证据与恢复放行另行实施。
