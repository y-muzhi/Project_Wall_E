# R92–R93 管理登记一致快照与独立核对

日期 2026-11-22。Windows 隔离源 `output/v22-dev-isolated`，固定 SQLite，在无监听端口的临时登记库验证。

- `snapshot-registry` 用登记原稳定锁、SQLite Backup API 和实际管理 Schema 核对产生自包含快照。实际数据库保留未检查点的已提交 WAL。快照重开后包含当时提交的登记记录，目录只含主文件和原回执。
- 快照发布后模拟丢回应。源管理登记继续更新，原操作重试仍读回先前的原快照，拒绝不同目录策略摘要或损坏字节。
- `verify-registry-snapshot` 根据固定原回执摘要、旧安装、目录摘要和实际 SQLite 重开验证。当活动库路径暂时不可读，仍核对原快照。错误回执、损坏主文件拒绝，未创建替代登记库或改变环境归属。
- 临时 Windows 适配模拟 POSIX 文件描述符、权限和排他发布。Linux 独立身份、宿主恢复冻结、新登记代次安装、旧原键归属核对以及外部目录与回执资产编排仍待验证或实施。此结果覆盖管理 SQLite 快照和独立核对。
