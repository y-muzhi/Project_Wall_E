# R145 Linux 固定管理回调的解释器交接

2026-11-22 香港时间。V2.2 Windows 独立分支。依据 V2.01 后端 4.6、4.11、4.12.3、7.7 和 8.2。

- 固定 CLI 的八个实际私有入口通过参数解析。验证已安装程序及运行包后，标准宿主引导进程使用原参数、私有 HOME／TMPDIR 和原标准输入交接给固定解释器。固定解释器直接进入现有目标校验并返回规范输出，其他解释器被拒绝。
- 本轮用 Windows 进程和文件 API 适配检查交接及拒绝分支。未以该测试代替 Linux setpriv、CPython 和 SQLite 映射的原生验证。本轮中段严格只读 SSH 探针在握手时超时。
