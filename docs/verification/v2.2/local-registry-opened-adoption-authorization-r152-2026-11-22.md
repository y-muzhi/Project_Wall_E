# R152 持久化待结算部署的采用授权

2026-11-22 香港时间。V2.2 Windows 独立分支。依据 V2.01 后端 4.10、4.11、4.12.3、7.9。

- 固定 `authorize-registry-recovery-deployment-adoption` 在同一所选恢复与派发暂停中重新核对停止和所选入口。管理员核准的源评估、宿主核对和原操作与同一只读凭证对应，按原操作只发布一次。
- 从实际管理 RESTORE 的封存 SQLite、目标应用正常停止和所选管理目录组成证据，在 Windows 独立环境验证拒绝错核对摘要、发布后回执缺失、同键读回、拒绝不同评估覆盖及拒绝错误读取摘要。凭证字节、原登记、原声明和暂停均保持。
- 使用 Windows 文件安全属性和 Linux 运行观察适配；本证据覆盖固定授权文件，登记写入和生产接入待后续。
