# V2.2 R46/R47 管理发布与原控制的浏览器专项

2026-11-21。Windows 隔离实施副本，实际管理 HTTP 和 WAL SQLite 验证目录、预览和原操作，独立 Firefox 使用由实际接口产生的计划与候选，并在测试拦截源控制网络时序。浏览器未连接现有服务。

- 管理者可见已登记同源目标。验证不足、源观察过期及已有原操作分别阻止执行。正式计划返回固定目标、同结构兼容、本地恢复要求和后续开放。只读身份和重复筛选不能借用目标。
- Firefox 检查维护观察、宽窄布局、无候选、错误和计划对照。确认前只有预览请求。模拟受理响应丢失，刷新后以同一原键读回已存在操作。模拟正在恢复的管理身份，早期核对仍等待；最终控制响应丢失后从原控制键取回，再显示原开放时间。浏览器无未捕获异常。
- 管理独立构建、Prettier 和 TypeScript 通过。此前全前端 602 项及两个独立构建通过。测试中修正夹具竞态、终态环境编号和管理恢复标志，最终全专项通过。Linux 固定目标与真实运营环境仍单列。
