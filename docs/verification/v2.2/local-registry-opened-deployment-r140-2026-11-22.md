# R140 已结算发布和恢复的原单元定位

2026-11-22 香港时间。V2.2 Windows 独立工作区。依据 V2.01 后端 4.11、4.12.2、4.12.3。固定清册的开放请求不含登记代次，代次由同一原步骤的维护授权保存。原核对从请求取代次会始终找不到对应单元。

- 应用与固定 SQLite 实际执行。宿主单元观测由 Windows 隔离夹具承担。实际存活单元与当前运行的二次绑定见 R141，Linux 原生待验。
