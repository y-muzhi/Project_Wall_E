### R426 退出 Firefox 后重新打开原资料

使用同一双站发布夹具，先让两站各自在实际 IndexedDB 留下独有的未保存草稿，确认服务端仍是原正文。分别关闭两组 Firefox 进程，再载入原来各自的磁盘资料。由 Linux `/proc` 核对实际 Firefox PID 更新及资料目录归属，原资料目录 inode 保持。新进程分别只显示本站待恢复文本，明确选择恢复并完成编辑，两个原 SQLite 的实际接口各自读回正确正文。采用 R427 最新固定后端再从独立来宾完整复验，同样读回并保存，两站停机和冻结后的原开放回执仍核对通过。两次来宾和验证退出均为 0。
