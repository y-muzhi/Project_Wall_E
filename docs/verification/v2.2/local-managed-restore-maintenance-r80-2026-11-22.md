# R80 从原管理恢复进入实际维护

日期 2026-11-22。Windows 隔离源 `output/v22-dev-isolated`，V2.2 实施分支，本批未提交。

- 在独立临时 SQLite 实际管理登记与真实进程内 HTTP 中完成预览和受理，通过 `enter-managed-restore` 的实际派发处理器登记原授权。Windows 适配固定宿主身份和文件描述符，其他管理事务、维护控制写入、稳定锁及源库只读复核走实际代码。

- 覆盖同一计划原授权、源程序与库身份、维护命令的真实关闭态、断回复以及复读。Ruff 修改范围通过。固定命令的 Linux 身份切换和原生命令调度尚未实测，当时 ARM64 SSH 在握手阶段超时。
