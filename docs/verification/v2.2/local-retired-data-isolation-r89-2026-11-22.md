# R89 普通应用隔离已保留的数据根

日期 2026-11-22。目标 Linux 固定入口，Windows 隔离源实施并以原生边界适配验证。

- 从当前安装锚推导稳定根和新数据目录。受管启动将原数据根和其他已就位代次的实际目录加入 `InaccessiblePaths`，不改宿主目录权限，限制应用更改挂载。普通启动入口在绑定监听前实际核验旧目录不能被遍历或打开。
- 固定启动参数包含旧根且排除活动根及不完整的临时准备目录。适配负例验证旧目录可遍历或可读均拒绝。真实 SQLite、普通应用开放、读写和停止回归通过。
- 当前 Windows 验证覆盖目录推导、固定命令和准入判断，未取得 Linux 挂载隔离证据。ARM64 恢复后以真实服务用户核验原根、新根和独立恢复副本，再运行完整恢复。实际功能依赖 [systemd.exec](https://www.freedesktop.org/software/systemd/man/latest/systemd.exec.html) 中的文件系统命名空间。
