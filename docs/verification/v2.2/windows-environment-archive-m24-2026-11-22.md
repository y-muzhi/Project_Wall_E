# M24 独立归档登记

2026-11-22 香港时间。V2.2 Windows 独立分支。依据 V2.01 后端 3.5、4.8—4.9、6.5 与前端 5.7—5.8。

- 真实管理 HTTP 与固定 SQLite 验证归档受理、原键重复读回、在途互斥、撤回、权限、环境版本与非法附带删除字段。固定宿主入口在本轮模拟稳定环境锁下复核实际工作目录及业务测试数据库的身份，执行真实管理事务。运行仍活动、非正常停止或资源声明在事务前漂移均保持受理，原回执丢失后同一操作可读回。
- 实际管理页和 Firefox 在 390、1300 像素下核对归档入口、触发确认、已受理、只读刷新、已归档、活动／归档筛选，以及已归档拒绝普通启动。只读账号没有提交入口。浏览器只产生一个归档 POST。真实受试工作区和 SQLite 摘要保持，九条独立资源声明同样保留。
- 本轮使用专用回环端口 58065，管理站、测试 Firefox 及其临时仓库目录均已结束与清理。Linux /proc、权限、systemd 和锁使用 Windows 夹具适配，真实 ARM64 的受管验收待做。
- 前端格式、严格类型、603 项、普通构建和管理构建通过。首轮全量前端临时副本缺 Python 路径，改用现有 WALLE_OFFLINE_TEST_PYTHON 后复跑通过。管理相关 Python 格式／Ruff 及 51 项登记专项通过。
