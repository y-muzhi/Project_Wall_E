## 隔离与宿主边界

每个工作区有独立临时目录、源码归档、启动 ISO、EFI 变量副本及 QCOW2 覆盖盘；覆盖盘只写入各自工作区 output 下本轮创建的目录，固定 R441 镜像只作为 backing image。QEMU 使用 TCG 软件模拟。宿主 Python 3.13.5 runner 顺序启动并同步等待本轮 QEMU 子进程，没有保留后台进程；QEMU 未打开 TCP 监听或端口转发，来宾没有虚拟网卡。每次结束后仅在 owner 标记和工作区 output 路径核对通过时清理本轮目录。未启动 WALL-E 用户服务或浏览器，也没有连接模型、计数、付费供应方或云资源。

最初的 WHPX 启动在来宾运行前失败，宿主返回 WHPX: No accelerator found, hr=80070005。随后在保持同一来宾、同一磁盘隔离和无网设置下用 TCG 完成回归。因此本记录不证明宿主 WHPX 或物理虚拟化可用。
