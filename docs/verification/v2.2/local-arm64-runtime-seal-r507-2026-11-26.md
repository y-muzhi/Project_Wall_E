# V2.2 ARM64 固定运行包封存与准入

日期 2026-11-26（香港时间）。在 Windows 宿主的无网 Ubuntu 24.04.5 AArch64 QEMU TCG 来宾复核 R501。开发分支为 `codex/2.2`，使用与 `codex/2.2-integration` 当前逐字节相同的运行准入源码。来宾使用 R462 已验证 ARM64 编译产物的副本、一次性覆盖盘和固件变量副本。

在私有构建前缀以非 root 构建用户执行原 `seal_runtime.py r507-local-arm --architecture aarch64`。实际重新编译稳定锁库、生成固定索引和宿主依赖清单，封存 4,324 项文件、18 项宿主动态库。封存运行包摘要为 `f6047f0a7aa9a3c8f64025d457a7ab69e6e143223f38589a7baf9e7f8872378a`。

首次封存及静态校验完成，验证夹具保留了 x86 的预期运行 ID，断言在非 root 准入前退出。修正该夹具后重新使用独立来宾，取得相同封存摘要，确认原平台、SQLite、宿主依赖、wheel 清单及编译输入与旧固定产物一致。以新的非 root 进程运行固定 `runtime.py probe`，实际识别 Python 3.13.18、SQLite 3.54.1、31 项依赖，退出 0。原 backing image 的大小和修改时间保持，两次测试覆盖盘、固件变量和串口均清理。

本次用已有编译产物重封，生产 ARM64 宿主和内部 Agent 准入不在此证据范围。
