# R138 同一 Firefox 中的双工作台隔离

2026-11-22 香港时间，Windows 独立验证。两份临时 Git 分支、Node 与 Python 依赖、普通和管理构建、实际 SQLite 和普通 WELL-E 进程分别独立。应用以两个不同实际环境身份构造公开入口。专用 Firefox 使用同一个测试配置打开两套已构建普通页面。

- 两套真实应用均完成创建需求、各自保存正文及重启读回。Firefox 实际打开两侧已保存的不同正文，两边都只显示自身内容。真实 `/api/v1/environment` 与文档读取成功。
- 初次刷新及再刷新均保留正确来源、环境与数据代次。将对侧真实历史状态故意置入当前页，刷新时应用拒绝使用这些历史信息，并恢复当前源的绑定和正文。
- 夹具最初遗漏公开配置的缓存控制和后端响应的身份头，页面正确拒绝。补齐本机测试网关转发的三项身份头及公开配置缓存要求后，实际页面通过。该测试使用固定公开描述和回环 HTTP 适配，尚未验证原生 Caddy、实际 TLS 或系统用户挂载。
