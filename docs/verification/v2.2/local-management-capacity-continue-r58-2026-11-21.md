# V2.2 R58 原启动的额度继续和撤回

2026-11-21。Windows 隔离副本，实际管理 HTTP、WAL 登记库与隔离 Firefox。管理事务以固定测试余量模拟缺内存，原启动等待时没有额度写入。开发者可撤回自己的等待启动或要求重新核对。其他开发者、只读身份或过期原版本被拒。额度仍不足时原操作继续等待；回放原控制键不重新计算，显式新控制键在额度可用时令同一原启动受理并保留四项租约。完整运行仍等待宿主。

Firefox 使用实际接口字段。显示缺少内存，模拟 CONTINUE 回执丢失，从本机原控制键取回结果而不重发，然后继续同一启动。另一个隔离上下文明确撤回原等待并显示已取消、宿主启动未派发。固定管理构建、类型及格式通过。未启动真实用户服务。
