# R75 恢复代次的只读核验与普通开放

2026-11-22。Windows V2.2 独立工作区。通过既有 Windows 固定 SQLite 及真实 FastAPI TestClient，使用临时目录和进程内应用。Linux 原生文件描述符、UID 和活网关进程事实由隔离适配提供。本专项没有监听服务。

- 使用现行业务命令创建两个代次的实际文档，将恢复代次关闭后通过真正应用读取正文与历史。旧代次拒绝，恢复模式的写入返回 403。
- 普通开放必须有同一原转换上的固定程序只读证明和网关证据。错误网关摘要拒绝；关闭态首次开放前不修理或恢复旧任务。模拟开放凭证保存后控制写入失败，控制与恢复库原字节保持。观察返回待核对，同一操作重试正式开放并正常结束。OPEN 与随后 CLOSED 均保留外发冻结，开放途径无原生任务权限。
- 私有确认以原数据代次做显式反例。网关可识别已核准的恢复前后代次并校验同一锁与原安装；ARM64 私有 Unix 套接字、实际网关进程和管理登记联验仍待完成。
- 临时 Python 专项通过，源码 Ruff 定向检查通过。测试产物由专用运行夹具清理。
