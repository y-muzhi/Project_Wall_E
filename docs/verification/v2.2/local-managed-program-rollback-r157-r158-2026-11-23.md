# R157—R158 受管发布与同结构程序回退

2026-11-23 香港时间。实施仓库 `codex/2.2`。依据 V2.01 后端 4.10、4.11、6.6、7.10。

- 原固定发布配置可明确携带前一安装及固定程序。固定源观察沿真实回退来源和兼容函数核对直接前置部署、锁、相同数据代次、数据库及目标新安装。普通发布仍需要原固定清单自身的兼容引用。
- 复用管理 `/catalog`、`/plans`、`/operations`、原控制键、已有宿主步骤和运行占用。回退计划、当前部署、前置包和审批相互绑定。原计划只给安全摘要，受保护前置路径不进入管理 HTTP。回退不接收数据库恢复参数。
- 在 Windows 独立回环测试执行 `backend/tests/infrastructure/test_v22_managed_program_release.py`。分别验证正常 RELEASE 和 ROLLBACK_CODE，管理 HTTP、实际 SQLite、受保护文件读回、候选分流、权限拒绝、重读原计划与执行结果、错误前置部署拒绝、原占用及同一运行释放均通过。业务库文件和数据代次保持。宿主测量、文件权限和固定包安装用了明确的本地适配，未把这些结果计作 Linux 原生验收。
- 本批可回退已核实的正常停止环境。指定原操作须为该环境当前已核实部署来源。仍未证明的维护结果保留阻塞。
