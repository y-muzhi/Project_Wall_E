# R116 原管理目录缺失后的现场核对

2026-11-22。独立 Windows 实际原、新两份 SQLite，使用 R94 固定目录及快照、R105 新锚和 R110 复核。采用类 Linux 文件权限和锁适配。

- 隔离移开原活动目录定义后，从绑定原快照回执的固定原字节重建读取依据，实际资产仍在原保护目录登记并核对。观察记录标注 ARCHIVED，原 UNKNOWN 操作继续阻断派发。
- 活动文件存在但改变时拒绝采用，封存原件有变化时拒绝。原活动文件恢复后，同一观察键因来源变化不能重复借用；先前同来源观察仍可按原凭证读回。
- 两套固定 SQLite 从选择、访问、诊断到安全开放／保留暂停均通过。未进行真实 ARM64 管理器、Caddy 或宿主外部调用。
