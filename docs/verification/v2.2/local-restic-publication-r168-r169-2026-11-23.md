# R168–R169 固定备份发布和原索引

2026-11-23，独立工作区 `output/v22-dev-isolated`、`codex/2.2`。依据 V2.01 后端 4.12.1、6.6、7.10 及 TC201-REL-10／11。

- 原命令 `publish-backup-snapshot` 先写持久意图，再从明确的封存目录写入固定本地仓库。首次无确认、仓库不符、既有未知标签、目标内容变化和停止后迟到快照均使用原意图核对。测试验证原写最多一次，取回不全不会登记发布回执。
