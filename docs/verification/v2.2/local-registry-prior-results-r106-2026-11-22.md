# R106 活动管理切换后的原回执只读

2026-11-22。独立 Windows 实施源和实际新旧 SQLite；测试 HTTP 在进程内。管理活动锚已经在夹具中切换，新登记继续受派发暂停。

- 新管理入口从受保护原安装链找到封存的原目录和 SQLite。原活库和原目录移出活动路径后，实际 GET 读回原请求、原控制回执及 UNKNOWN 状态，保留原快照摘要。
- 当前登记的普通同键读取不会查到旧结果。旧代次请求头、向旧回执写入、当前可读但原目录无权的账号均拒绝。原提交者和同时满足原权限的管理者通过。
- 损坏封存目录拒绝并标明无法核实。恢复临时夹具原字节后返回原回执，活库和原操作不受影响。旧锚描述符不能取得写锁。
- 首次夹具把旧回执编码成了无原协议换行的 JSON，按正常持久编码修复后复验通过。浏览器界面与实际原生入口在各自后续段核对。
