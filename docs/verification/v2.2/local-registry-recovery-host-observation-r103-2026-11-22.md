# R103 原管理目录和实际登记环境观察

2026-11-22。独立 Windows 实施源、实际临时 SQLite 及 Windows 文件描述符适配。固定宿主入口 `observe-registry-recovery` 在原暂停和锁下核对已登记清册。

- 同一原目录的固定事实中，已存在且摘要匹配的资源、缺失助项和无实际绑定登记分别记录。修改同一长度的资产后原观察号不变化，新观察返回不同事实。活动登记、原控制和 SQLite 不修改。
- 独立的真实关闭环境校验固定程序、原锁、原控制、数据文件和根身份，返回实际 CLOSED。错数据代次登记记录差异，错宿主保持 UNKNOWN。
- 已实现已核验运行和实际锁、Unix 套接字的核对路径。其 Linux 原生运行未执行。已确认关闭、存在、缺失或未知均不用于自动释放原容量。
