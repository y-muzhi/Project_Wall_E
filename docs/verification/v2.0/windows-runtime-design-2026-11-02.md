## 采用的设计

WIN20-ISOLATION-1采用LPAC、受管ACL、WFP及Job。最小本机Runtime Guard只承担OS权限／进程职责，业务调度仍归现有后端；Guard独占Job句柄并绑定控制方真实进程，分别处理两者退出。挂起启动／持久关联、普通子进程／外部代理、阶段静止／完整停止、未知及自动降级边界均已展开。RuntimeBoundaryObservation、绑定及TaskView.runtime提供对应证据与安全投影；不新增浏览器OS控制入口。

以上是来源核对及设计选择，不是这些机制已在本项目运行成功。首次系统环境准备可能需管理员，但本轮没有任何系统修改／安装授权或执行。
