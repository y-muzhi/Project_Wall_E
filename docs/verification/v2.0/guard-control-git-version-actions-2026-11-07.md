# Guard 固定 MinGit 版本探针与原动作验证（2026-11-07）

在当前 V2.0 工作区使用 Windows、项目锁定 Python／SQLite 及实际 MinGit 2.56.0.windows.4。业务库和用户服务保持原现场。测试使用临时目录、测试自有进程／Job 和私有技术记录。

- 固定 PREPARE 拒绝自由路径、参数、PID 和替换控制方字段。以真实控制方和 scope 重建三个子端的描述符，先保存原意图再分配。相同输入重放原 ACK，改变 IO nonce 拒绝。实际挂起创建、恢复及有界输出采集得到固定版本、退出码 0、空 stderr 和双端 EOF。
- 原动作入口核对当前控制方及程序租约，也可转入已批准的原 scope 窄恢复门。实际版本进程的创建、恢复、停止及释放都回放各自原记录。OBSERVE 读取原动作和活资源事实。STOP 先于 PREPARE 时封闭原 nonce，迟到 PREPARE 不分配。RELEASE 未满足前置条件时不保存原释放意图，释放成功关闭原句柄并保留共享 MinGit 目录。
- 实际本机管道与控制方 owner 检查验证错误程序端口和已关闭连接都无法派发 STOP。该检查的保护包准入使用测试端口，磁盘上的原登记保持无准入；窄恢复与动作入口的真实保护程序正向联调仍待执行。
