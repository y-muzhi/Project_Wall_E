# 草稿身份事件证明与权威元数据回执 v1（待确认）

依据：后端 APP-DOC-CMD-C02 L1351–1365 要求保护创建来源、生成权威派生值与时间；SHR-BLOCK L302–324 约束完整身份与来源；已确认 D-004 稿 B 要求撤销恢复原 ID 且高水位不回退，恢复限于同草稿基线/事件映射。前端 BND-EDITOR 与自动保存规则要求等待响应时保留较新的本地输入。D-008 已解决来源对象为持久编辑会话，但不定义这份身份事件证明。

当前真实实现：开始草稿同时保存初始 BlockState、CURRENT 基线版本和 EDITING 会话。纯算法 assign_identities 可以从上一快照或初始基线恢复身份。实际缺口有两种：新块保存后删除，再撤销恢复，初始基线没有它；新块在一次自动保存之前就被插入又删除，服务器只收到提高的 next_block_id，没有收到这个块。不能把这些情况永久拒绝为“不支持撤销”，也不能仅凭当前会话 source_id 或相似文本接受任意历史 ID。

另外，前端新块的本地创建时间尚未获服务器确认；后端第一次保存产生权威时间后，正在等待响应的编辑与 undo 历史仍可能引用本地时间。接续必须按实际提交与回执的身份映射更新创建事实，不能把迟到响应整份覆盖较新的正文。

## 推荐的事件证明

在现有内部表之外增加同目录 SQL 中的两张草稿生命周期表。不改公开 BlockState、DocumentReadModel、请求字段、接口数量或来源对象。

- `manual_block_allocation_ranges`：每次成功保存若 next_block_id 提高，原子记录 `[旧 next, 新 next)` 的分配范围和本次服务器操作时间。该范围是当前草稿提交的分配事件证明；不逐个展开区间，不能因大高水位申请占用海量内存。高水位不回退；区间不重叠；原始基线中的 ID 仍由真实基线证明。
- `manual_block_origins`：实际出现过的新区块登记不可改的创建事实。新身份只能是 USER/MANUAL_EDIT/本草稿会话 ID；创建时间取首次记录该身份分配范围的服务器操作时间。客户端时间只作完整输入结构校验，不作为新的持久事实。区块随后删除，证明仍保留至草稿结束。
- 在分配范围中已分配但此前未出现在保存快照中的 ID，可在以后撤销恢复时首次出现。使用该范围的创建来源和时间登记出生事实，而不是把它当成任意旧模板/AI/其他会话的来源。
- 已有区块及已登记出生事实的创建字段不得改变；恢复时使用实际基线/出生证明。内容、区块类型、章节路径由真实 Markdown 解析产生；恢复的最近修改来源和时间为本次实际人工保存。不按文字相似度认定恢复。范围之外、其他草稿、错误署名或试图改变既有创建事实均 DOCUMENT_INVALID。
- 区间、出生证明、草稿正文/BlockState/版本同一短事务提交；任一点失败全部回滚。保存没有幂等键，响应不明先读取草稿，不能根据网络错误回退高水位或重新分配。
- 完成/取消在共同事务清理这些临时证明，随后删除草稿/上下文、释放占用并关闭 D-008 会话。历史 CURRENT/Revision 中的来源仍通过永久会话关系验证；不删除该会话。

这个方案将创建时间明确为服务器第一次接受分配事件的时间，和前端尚未确认的本地时间区分。没有额外的客户端事件接口，持久证明来自既有成功保存及其高水位；这项具体算法须本次确认。

## 回执接续

前端按实际发送的需求/草稿 ID、expected_version、完整提交快照与对应回执建立证明，确认同一身份与范围。将权威创建字段写入本编辑会话的出生账本和同 ID 的历史缓存；当前本地删除的 ID 也保留该事实，供以后 undo 使用。不重新生成 ID，不把同文字的新块当旧块。

回执只更新被确认的基线/版本及创建事实。迟到回执不覆盖较新本地正文、顺序、选区或高水位；最新待保存快照继续从真实当前编辑状态生成，保留尚未确认的修改。未经对应提交证明的回执、跨需求/草稿回执和过期生命周期回执拒绝接续。响应未知的 GET 恢复遵循现有版本/本地缓存规则；不凭一个相似文档猜历史出生事实。

## 迁移与验证

增加独立内部迁移，保持已批准 001–003 和所有资源字节不变。迁移前备份。旧草稿若没有提高初始高水位且当前身份全部来自实际初始基线，可以保留并按已证明基线继续；已有新增/删除分配但无法证明历史分配与出生事实时拒绝升级，保留原数据，不根据 ID/时间猜历史。当前项目没有生产数据库，现有命令尚未实现草稿保存。

真实文件 DB 验证：新建→保存→删除→保存→恢复；插入/删除发生于同一首次快照之前；跨会话/未分配身份/伪造创建事实拒绝；所有关系/时间/高水位及正文的原子回滚；提交后丢回执读事实恢复；迁移成功/拒绝均保存原数据。真实编辑器验证：提交等待期间继续编辑、删除已提交新块、迟到/失序回执、撤销/重做与当前光标，高水位和出生事实不回退。

阻塞：完整 APP-DOC-CMD-C02 和 P7 自动保存元数据接续；APP-DOC-CMD-C03 的真实草稿来源继承也需该证明。需求/正文/历史查询、已完成的生命周期与草稿开始/取消、HTTP 公共边界及其他能力可继续。确认不包括真实 AI 调用预算或效果验收。
