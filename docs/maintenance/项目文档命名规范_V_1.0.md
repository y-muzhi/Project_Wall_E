# 项目文档命名规范

日期：2026-10-18。用户确认仅统一项目文档名称，保留协议版本与历史修订批次。此次为文件命名维护，不变更已收口功能或开启下一大版本。

## 1. 命名规则

- 项目版本标识统一置于扩展名前，以`_V_1.0`结尾；删除原`WALL-E.V1_0.6.`前缀中的版本部分。
- 保留WALL-E名称和文档主题；历史修订批次V1／V2／V3属于记录身份，继续保留，避免不同迭代同名。
- 程序协议、Manifest、Schema、采用JSON、共享夹具、验证日期和既有验证批次名称保持原名。未带项目版本的通用说明、导航和模板不批量追加版本。
- 文档正文中的目标软件版本、原始规格版本、sync修订号、历史日期及原始桌面来源名称不因文件重命名而改写。
- 原始前后端归档保留原文件名及原始字节／SHA-256，因冻结正文含原文件名互链，改名将使历史链接失效；冻结提案、采用文件和资源不修改。
